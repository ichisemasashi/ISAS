### 2.5 API（詳細設計 §2.5）

| 項番 | 出典（経路・方法） | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| V2P1-2.5-01 | `GET /api/user/gantt` | API | 自分 | 各行に `execution_status` |
| V2P1-2.5-02 | `POST /api/user/gantt` | API | クライアントが `done` を送る | 保存は常に `not_started` |
| V2P1-2.5-03 | `PUT /api/user/gantt/{id}` | API | `execution_status` を送る | 三値に更新。省略時は既存維持 |
| V2P1-2.5-04 | `PUT` 不正値 | API | `execution_status: "x"` | `execution_status_invalid` |
| V2P1-2.5-05 | `GET /api/user/gantt/daily` | API | `range=today`、statuses 省略 | 今日窓に重なる、未着手＋着手中。並び start_at, id |
| V2P1-2.5-06 | `range=week` / `last_week` / `around7` | API | 月曜始まりの今週・先週、前後7日（15暦日）の窓 | 重なり判定どおり。旧 `days7` は `range_invalid` |
| V2P1-2.5-14 | 遅れ | API | 終了が現在以前の未完了行・完了行 | 未完了は `overdue: true`、完了は偽。終了ちょうどで真 |
| V2P1-2.5-15 | 遅れを期間に足す | API | 期間より前に終わった未完了行 | `today` / `week` / `around7` に載る。`last_week` には足さない。状態フィルタは効く。管理者の横断一覧も同じ |
| V2P1-2.5-16 | `PUT /api/user/gantt/{id}/status` | API | 日次一覧の読み込み後に作業画面で表示名・時刻を変え、状態 API で状態を変える | 状態だけ変わり、表示名・時刻・対象は変わらない。`version` が進む |
| V2P1-2.5-17 | 状態 API のエラー | API | 不正値・欠落・壊れた JSON／他人・削除済み・未存在／圃場0／未ログイン | `execution_status_invalid`／`gantt_not_found`／`no_fields`／`unauthorized` |
| V2P1-2.5-18 | 版照合 | API | 古い `version`・整数でない `version` で PUT | `gantt_conflict`。内容・版は変わらない |
| V2P1-2.5-19 | 版照合（成功・省略） | API | 最新の `version`、または `version` 省略で PUT | 保存され、`version` が 1 進む |
| V2P1-2.5-20 | 衝突時の画面 | 画面 | 作業画面の保存が `gantt_conflict` | 案内を出し、`GET /api/user/gantt` で読み込み直す。保存時は読み込んだ `version` を送る |
| V2P1-2.5-06b | `range=all` | API | 期間なし | 状態フィルタのみ。削除除く全件 |
| V2P1-2.5-07 | `statuses=` 空 | API | 空文字 | 成功の空配列 |
| V2P1-2.5-08 | `range` 不正 | API | `range=month` | `range_invalid` |
| V2P1-2.5-09 | `statuses` 不正 | API | 未知トークン | `statuses_invalid` |
| V2P1-2.5-10 | 重なり境界 | API | 窓終端ちょうど開始／窓開始ちょうど終了 | 重ならない |
| V2P1-2.5-11 | ソフト削除 | API | 削除済み行 | 日次に出ない |
| V2P1-2.5-12 | 圃場0 | API | daily GET | 第2版工程4で緩和（成功・空可）。作成・更新等は従来どおり `no_fields` |
| V2P1-2.5-13 | 管理者 | API | 管理者 Cookie | `forbidden` |
