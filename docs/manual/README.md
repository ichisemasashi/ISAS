両文書の版は1.0、対象baselineは`v1.0.0`である。この版番号は文書・実装baselineを示し、本番稼働承認を示さない。本番承認はADR-0021のrelease manifest、全gate、法域別の二人承認で決める。

## 文書の使い分け

- 通常の操作／点検は本manualを入口にする。
- 緊急時に「次に何を実行するか」は[operations runbook](../operations/README.md)を正とする。
- 「なぜその方式か」は[ADR](../design/ADR/README.md)を正とする。
- 現在完了している範囲は[開発工程 §6](../開発工程.md#6-マイルストーンと現在地)を正とする。
- CSV列定義は[CSVガイド](../CSVデータ移行・出力ガイド.md)を正とする。

## 配布前の管理者作業

1. 両guideの`未設定`欄を法域／組織の値で埋めた配布版を作る。
2. URL、問い合わせ、緊急、農薬、privacy窓口を実際に到達確認する。
3. role／scope、対応端末、利用言語、保持方針を組織の構成と照合する。
4. UIまたは運用がmanualと異なる場合、利用開始前にmanualか構成を直す。
5. 改訂日、改訂者、承認者、対象releaseを記録し、古い版を現場から回収する。

レビュー結果は[運用文書v1.0レビュー記録](レビュー記録_運用文書_v1.0.md)を参照する。
