## 手動チェックリスト（詳細設計 §7）

実データ（自分の圃場を持つ利用者・招待メンバ・必要なら管理者）で確認する。

1. [ ] パソコンで今日／今週のガント作業を未着手／着手中／完了に変えられる（工程1）
2. [ ] 面積以外の作業に作業時間とチェックを付けられ、無くても日次が使える（工程2）。実行状態は自動では変わらない
3. [ ] 招待利用者と管理者が、パソコンと狭幅でメモを投稿・閲覧・返信・検索・ブックマークできる（工程3・4）
4. [ ] 狭幅で日次を閲覧できる（変更できない）。下部ナビから指示の進捗色・日誌へ辿れる（工程4）
5. [ ] 公開済み親メモに作業を付け、外し、別作業へ付け替えられる（作成者および管理者。パソコンと狭幅）。スレッド内の「紐づいた作業」に作業名が出る（これが要約。別の「要約」欄は無い）。下書き・返信には付けられない
6. [ ] 紐づけたあと、塗り・％・実行状態・時間・チェック・指示／日誌が自動では変わっていない
7. [ ] パソコンの作業／ガントで作業を選び「一覧から消す（ソフト削除）」すると、メモ側スレッドの「紐づいた作業」に「削除済み」と分かる。メモをソフト削除すると通常の一覧から紐づきが見えない
8. [ ] 要求 §2 の対象外が画面に無い。§8 の任意が未実装でも受入を止めない
9. [ ] 作業／ガント／塗り／指示で使った作業名（および作業の表示名）が、各画面の作業名入力の候補から選べる
10. [ ] 受けた指示の詳細で、進行中・未記入なら「日誌を投稿する」が分かり、一覧に「日誌未記入／日誌済」が出る
