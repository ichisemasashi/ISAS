### 2.2 API（詳細設計 §2.2 の表）

JSON は工程1と同じ形。区画ファイルと下地画像だけ `multipart/form-data`。自分の利用者セッションが無い呼び出しは `unauthorized`。管理者セッションでは `forbidden`。他人の圃場 ID は失敗 code 表の `field_not_found`（存在を分けて出さない）。

| 項番 | 出典（経路・方法） | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| P2-2.2-01 | `GET /api/user/place` 未設定 | API | 作業場所が無い利用者 | `ok: false`, `code: place_unset` |
| P2-2.2-02 | `GET /api/user/place` 設定済み | API | 保存したあと | `ok: true` と東西南北 |
| P2-2.2-03 | `PUT /api/user/place` | API | `{ west, south, east, north }` 正しい | 範囲が置き換わる |
| P2-2.2-04 | `PUT /api/user/place` あと下地 | API | 下地がある状態で場所を変える | 古い下地は使えない（削除）。圃場の行は消さない |
| P2-2.2-05 | `GET /api/user/basemaps` | API | 呼ぶ | 3種それぞれが取込済みかどうか |
| P2-2.2-06 | `PUT /api/user/basemaps/{kind}` | API | JPEG または PNG。`standard` / `aerial` / `satellite` | 取込できる |

| P2-2.2-16 | `kind` 以外 | API | 下地名が3種以外 | `basemap_kind` |
| P2-2.2-17 | 地理院タイル URL | 禁止 | API を探す | 地理院のタイル URL を返す API は無い |
| P2-2.2-18 | 未ログイン | API | Cookie 無しで工程2 API | `unauthorized` |
| P2-2.2-19 | 管理者セッション | API | 管理者 Cookie で工程2 API | `forbidden` |
| P2-2.2-20 | 他人の fields.id | API | GET/PUT/DELETE/split に他人の id | `field_not_found`。自分の台帳は変わらない |

## 3. 処理の規則

| 項番 | 出典 | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| P2-3.1-01 | ログイン中の利用者にだけ紐づく | API | 他人の id | 見えない・変わらない |
| P2-3.1-02 | 管理者は持たない | 禁止 | 管理者 | 作業場所・下地・圃場を持たない |
| P2-3.1-03 | 取消ししても圃場は消さない | 保存 | 利用者を取り消す | 工程2では行は残る。入れないので使えない。再招待で同じ行。圃場も残る |
| P2-3.2-01 | 面積0は保存しない | API | 面積が取れない形 | 保存しない（`shape_not_area`） |
| P2-3.2-02 | 重なってよい | API | 重なる2枚 | 保存できる |
| P2-3.2-03 | 工程2は塗りの有無を見ない | API | 分割・合筆 | 工程2では塗りの拒否はしない |
| P2-3.3-01 | 順序 | 画面 | 場所の前に下地／圃場 | 場所を先に決める。3種が揃う前でも地図は開ける。無い種は切り替えられない。空中写真が無ければ下地なし |

座標は経度緯度（WGS84）。取込が他の座標系なら保存前に直す。面積は保存しない。読むときに㎡を求め、一覧 ha（㎡÷10000）小数第2位、詳細 ㎡整数。

| 項番 | 出典 | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| P2-3.2-04 | ha の丸め | 画面・API | 50㎡未満の圃場 | 一覧の ha は小数第2位（0.00 になり得る）。詳細の ㎡ は正の整数。ha が 0 でも ㎡ が見えること |
