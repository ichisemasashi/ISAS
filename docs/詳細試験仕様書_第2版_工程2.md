## 3. 処理の規則

| 項番 | 出典 | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| V2P2-3.2-01 | 親外側・重なり | API | 親期間外・時間帯重複 | 許可 |
| V2P2-3.3-01 | 重複名 | API | 同じ親に同名チェック2件 | 許可 |
| V2P2-3.4-01 | 状態非連動 | API | 時間・チェック追加後 | `execution_status` は変わらない |
| V2P2-3.4-02 | ％非連動 | API | 同上 | progress ％規則は第1版のまま |
| V2P2-3.4a-01 | 日次で完了・チェック残り | 画面 | 日次一覧で `checklist_done` < `checklist_total` の行を完了にして保存成功 | 「実行状態を保存しました。完了にしましたが、まだのチェックが n 件あります。作業を開いて確認してください」（英語も同趣旨） |
| V2P2-3.4a-02 | 注意を出さない場合 | 画面 | 残り 0／完了以外／チェックなし | 成功文言だけ |
| V2P2-3.4a-03 | 作業画面で完了・チェック残り | 画面 | 選択中の作業を完了で保存成功（`pending` が n 件） | 「作業を保存しました。完了にしましたが、…n 件…」。完了以外で保存したときは成功文言だけ |
| V2P2-3.4a-04 | 持ち越さない | 画面 | 保存失敗（`gantt_not_found`・`gantt_conflict` 等） | 注意を出さず、覚えた残り件数を消す |
| V2P2-3.4a-05 | 日次の印 | 画面 | 完了でチェック残り／完了で全部やった／着手中でチェック残り | 1行目にだけ「チェック残り」の印 |
| V2P2-3.4a-06 | サーバは拒まない | API | `pending` が残る作業を `PUT .../status` で `done` | 成功し、状態は完了 |
| V2P2-3.5-01 | 親ソフト削除 | API | 行 DELETE | 未削除の子もソフト削除。通常一覧に出ない |
| V2P2-3.5-02 | 題名ソフト削除 | API | 題名 DELETE | 配下の行の子も通常操作から消える |
| V2P2-3.5-03 | 親削除後の子 | API | GET/POST 子 | `gantt_not_found` |
