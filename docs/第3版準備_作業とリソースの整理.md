## 1. 目的と経緯

第2版のタスク管理は、ガント作業に実行状態（未着手／着手中／完了）を付け、日次一覧で回すものである。作業の開始・終了は人が手で入れ、作業どうしのつながりはない。

米の作業は、暦ではなく生育で時期が決まり（例：防除は出穂の何日後）、同じ作業を圃場ごとに順に行い、毎年ほぼ同じ計画を繰り返す。これを管理するには、第2版の「予定の行に状態を付ける」形では足りない。

本書では次の順で整理する。

1. 米農家の1年の作業を一覧にする（§2）。
2. 作業を管理するための項目を定義する（§3）。
3. 作業以外に管理すべきリソースを定義する（§4）。
4. 作業とリソースのどちらにも当たらない管理対象を定義する（§5）。
5. 現状（第2版）の ISAS が持つ項目と照らし合わせる（§6）。
6. 決めていないことを挙げる（§7）。

## 3. 管理する作業の定義

### 3.1 型と作業

すべての項目は、次の二層を前提にする。

| 層 | 意味 | 例 |
|---|---|---|
| 型 | 毎年ほぼ同じ作業の決まり（栽培暦の1行） | 穂肥 |
| 作業 | 型を、ある年度のある対象に当てはめた1件 | 2026年度の圃場Aの穂肥 |

型は毎年使い回し、年度ごと・対象ごとに作業を作る。各項目の定義には、型と作業のどちらが持つかを書く。

### 3.2 1年を通して管理する項目（すべての作業が持つ）

#### 3.2.1 作業内容

- **定義:** 何をする作業か。
- **持つもの:** 型が持つ。名前と、やり方の標準（使う資材と標準の量を含む）。作業は型の作業内容を受け継ぐ。
- **決まり:** 実際に使った資材と量は、作業内容ではなく結果に残す。
- **例:** 穂肥（化成肥料 20kg/10a）

#### 3.2.2 フェーズ

- **定義:** 1年の作業の段階。次の8つのどれかとする。
  1. 計画・準備
  2. 種子・土づくり
  3. 育苗・田の準備
  4. 田植え
  5. 生育管理
  6. 出穂
  7. 収穫・調製
  8. 片付け・精算
- **持つもの:** 型が持つ。
- **決まり:**
  - 1つの型は1つのフェーズに属する。
  - 何か月も続く作業（水管理など）は、始まるフェーズに属する。
  - フェーズは作業のまとまりであり、日付ではない。月は目安である。

#### 3.2.3 前提条件

- **定義:** 作業を始めてよくなる条件。
- **持つもの:** 条件の中身は型で決める。満たされたかどうかは、作業ごと（対象ごと）に判断する。
- **種類:** §3.4 のとおり、日時を決める条件と、当日にできるかの条件に分かれる。
- **決まり:**
  - 条件は「かつ」「または」で組み合わせられる。例：いもち病の防除は「発生予察が出た、**または**病斑がある」。
  - 日時を決める条件から予定日を出す。当日にできるかの条件は予定日を動かさず、その日にやれるかどうかだけを判断する。

#### 3.2.4 日時

- **定義:** いつやるか、いつやったか。
- **持つもの:**
  - **型:** 起点からの日数と、適期の幅の日数（相対値）。
  - **作業:** 次の3つ（実際の日付）。
    - 予定日：前提条件から出した目安の日
    - 適期：いつからいつまでにやればよいか
    - 実施日時：実際にやった開始と終了
- **決まり:**
  - 前提条件がまだ決まらないあいだは、型の標準の日数で見込みを出す。起点となる結果（田植日・出穂日など）が記録されたら、予定日と適期をずらし直す。
  - 人が予定日を手で直すこともできる。
  - **遅れ**とは、適期の終わりを過ぎても、完了・不要のどちらにもなっていない作業をいう。

#### 3.2.5 対象

- **定義:** 作業をする相手。1件の作業は1つの対象に対して行う。
- **持つもの:** 型は対象の種類を持ち、作業は具体的な対象を持つ。
- **種類:** §4 で定義するリソースのうち、作業の相手になるもの（年度、圃場、水利、品種、資材、機械、施設・設備、苗、ロット、書類・記録、お金）。
- **決まり:**
  - 同じ型を複数の対象に行うときは、対象ごとに1件の作業にする。例：田植えを圃場5枚にすれば5件である。
  - 対象の属性が作業の日時を変えることがある。例：圃場の作付の品種によって、標準の日数が変わる。

#### 3.2.6 状態

- **定義:** 作業がどこまで進んだか。
- **持つもの:** 型は完了の目安を持つ（例：浸種は積算水温が約100℃に達したら）。作業は状態の値を持つ。
- **値:** 未着手、着手中、完了、不要（不要は §3.3.2）。
- **決まり:**
  - 完了にしたら、実施日時を残す。
  - 完了した作業は、ほかの作業の前提条件「先行作業」を満たす。

#### 3.2.7 結果

- **定義:** 作業をして得た値や、決めたこと。後の作業の前提条件・日時・集計に使う。
- **持つもの:** どの結果を残すか（項目と単位）は型が決める。値は作業が持つ。
- **種類:**

| 種類 | 中身 | 例 |
|---|---|---|
| 決めたこと | 選んだもの、決めた日 | 作付の品種、刈り取り日 |
| 使った資材と量 | 名前・量・単位・倍率 | 化成肥料 20kg/10a、農薬名と1000倍 |
| 観測値 | 値・単位・観測日 | 茎数、積算水温、出穂日 |
| 収穫物 | 量・品質 | 重量、袋数、水分、等級 |

- **決まり:**
  - 結果は、その作業の対象に付く。例：出穂日は圃場Aの結果である。
  - 前提条件の「結果の値」と「起点からの日数」は、この結果を参照する。
  - 一度残した結果は、その年度の精算まで参照できるようにする。
  - 書類は結果を書き写さず、結果から作る（§4.5.2）。

#### 3.2.8 担当（手分けする場合だけ）

- **定義:** 作業をする人（§4.3.7）。
- **持つもの:** 作業が持つ。
- **決まり:**
  - 1人以上を付ける。1人で営農するなら省いてよい。
  - 地域の共同作業では、出る人を担当にする。

### 3.3 一部の作業だけが使う項目

#### 3.3.1 繰り返し

- **定義:** ある期間のあいだ、決まった間隔で何度も行う作業の持ち方。
- **持つもの:** 型が持つ。
  - **期間:** 始まりと終わりを前提条件で表す（例：田植えが完了してから、落水が完了するまで）。
  - **間隔:** 毎日、毎日朝夕、週1回、2週ごと、など。
- **決まり:**
  - 作業は「期間全体の1件」と、その下の「回」の二段で持つ。
  - 期間全体の状態は、始まると着手中、終わりの条件で完了になる。
  - 回ごとに実施日時と結果を残す（例：生育調査の茎数）。
  - 間隔を過ぎても次の回の記録がなければ、その回を遅れとする。
- **使う作業:** W-15 育苗管理、W-25 水管理、W-26 畦の草刈り、W-28 生育調査、W-37 鳥獣害の見回り

#### 3.3.2 状態「不要」

- **定義:** 状況から、やらないと決めた作業の状態。
- **持つもの:** 型が「不要になりうる」かどうかを持ち、作業が不要を選ぶ。
- **決まり:**
  - 不要を選べるのは、型が「不要になりうる」となっている作業だけとする。
  - 不要にした理由を短く残す（例：欠株なし、予察なし）。
  - 不要にした作業は遅れにならない。
  - 後の作業の前提条件「先行作業」については、完了と同じく満たしたとみなす。
- **使う作業:** W-23 補植、W-27 中期除草、W-32 いもち病の防除、W-36 カメムシ防除の2回目

### 3.4 前提条件の種類

外部が決める日と資源の取り合いは、新しい項目を作らず、前提条件の種類として持つ。

| 種類 | 中身 | 例 |
|---|---|---|
| **日時を決める条件** | | |
| 先行作業 | ほかの作業が完了（または不要）になっている | 代かきが済んでいる |
| 結果の値 | 観測した値が基準に達している | 茎数が目標の約8割 |
| 起点からの日数 | ある結果の日から何日前・何日後 | 出穂の7〜10日後 |
| 暦 | 指定日・締切（外部が決める日を含む） | 水路の掃除の指定日、確定申告の締切 |
| **当日にできるかの条件** | | |
| 天候 | その日の天気 | 晴れて籾が乾いている |
| 資源の空き | 機械・施設・資材・人が使える | コンバインが空いている |

### 3.5 項目どうしの関係

1. 型が、作業内容・フェーズ・前提条件・対象の種類・完了の目安・残す結果を決める。
2. 型を対象（例：圃場A）に当てはめて、作業を作る。
3. 前提条件から日時（予定日・適期）が出る。
4. 作業をして、状態を完了（または不要）にし、結果を残す。
5. その結果と状態が、後の作業の前提条件を満たし、後の作業の日時を決める。

### 3.6 項目が必要になる時期

§3.2 と §3.3 の分け方は、2.2 の作業でその項目が必要になる時期から決めた。●はそのフェーズの作業で必要になることを表す。

| 項目 | 計画・準備 | 種子・土 | 育苗・田 | 田植え | 生育 | 出穂 | 収穫 | 片付け・精算 |
|---|---|---|---|---|---|---|---|---|
| 結果 | ● | ※1 | ● | ● | ● | ● | ● | ● |
| 対象の種類（圃場以外） | ● | ● | ● | ● | ※2 | ● | ● | ● |
| 繰り返し | | | ● | ● | ● | ● | ● | |
| 状態「不要」 | | | | ● | ● | ● | | |

- ※1 3月に新しく残す結果は少ないが、1月に決めた作付（品種）を見て作業する。
- ※2 6〜7月の作業は圃場だけが対象である。
- 結果は、一度残したものを後のフェーズが見続ける（例：1月の作付は12月の精算まで、8月の出穂日は収穫まで）。
- 対象の種類は、個々の種類は季節限定だが、全体では1年じゅう要る。12〜2月には圃場の作業が1件もない。

## 4. 管理するリソースの定義

作業以外に管理するもの（作業の対象・前提条件・結果・担当から参照されるもの）を、リソースと呼ぶ。全部で15種類である。

### 4.1 分類と定義の観点

| 分類 | 性質 | リソース |
|---|---|---|
| 年度の枠 | 毎年作り、その年の作付・作業・結果をまとめる | 年度、作付 |
| 台帳 | 年をまたいで続く。登録して、ときどき直す | 圃場、水利、品種、資材、機械、施設・設備、人、関係先 |
| 流れ | 作業の途中で生まれ、形を変え、使い切ると終わる | 苗、収穫物のロット |
| 記録 | 日々たまっていく。年度の締めのあとも残す | 気象、書類・記録、お金 |

各リソースは次の観点で定義する。当てはまらない観点は書かない。

- **定義**
- **1件の単位:** 何を1件とするか
- **主な属性**
- **続く期間**
- **状態:** 段階があるものだけ
- **数量・取り合い:** 量が増減するか、複数の作業で使い合うか
- **関係:** ほかのリソースとのつながり
- **作業との関係:** 作業のどの項目から参照されるか

### 4.2 年度の枠

#### 4.2.1 年度

- **定義:** 1回の米づくり（計画から精算まで）をまとめる期間。
- **1件の単位:** 1年度（例：2026年産）。
- **主な属性:** 名前、開始日、終了日、予算（売上・経費の見込み）。
- **続く期間:** ずっと残す。過去の年度は比較と振り返りに使う。
- **状態:** 計画中 → 実施中 → 締め（精算と申告が済み、結果を直さない）。
- **関係:** 作付・作業・苗・ロット・書類・お金は、どれか1つの年度に属する。
- **作業との関係:** すべての作業が1つの年度に属する。対象（振り返り、精算）。
- **注意:** 前後の年度は時期が重なる。12月には、今年度の精算と翌年度の計画が同時に進む。

#### 4.2.2 作付

- **定義:** ある年度に、ある圃場で、どの品種をどう作るかの決定。
- **1件の単位:** 年度 × 圃場で1件。
- **主な属性:**
  - 年度、圃場、品種
  - 作型（移植・直播）
  - 作付面積（圃場の面積と違うことがある）
  - 用途の区分（主食用・加工用・飼料用など。交付金に使う）
  - 栽培方法（慣行・特別栽培）
  - 目標（目標収量、目標茎数など。前提条件の「茎数が目標の約8割」に使う）
- **続く期間:** 年度ごとに作り、年度の締めで固定する。
- **状態:** 計画中 → 確定。
- **関係:** 圃場、品種、年度。苗の必要箱数、資材の必要量、ロットの元になる。
- **作業との関係:**
  - 作付計画（W-02）の結果としてできる。
  - 作付が決まると、作業の型を当てはめる元になり、作業の件数（圃場ごと）と日程（品種ごと）が決まる。

### 4.3 台帳

#### 4.3.1 圃場

- **定義:** 作付の単位となる田んぼ1枚。
- **1件の単位:** 畦で区切られた1枚。
- **主な属性:**
  - 名前、形、場所、面積
  - 所有（自作地・借地）、地主（関係先）
  - 水を引く取水口（水利）、メモ
- **続く期間:** 年をまたいで続く。分割・合筆や借地の返却で変わるが、過去の作付と結果のために、使わなくなった圃場も消さずに残す。
- **関係:** 作付、水利、関係先（地主）、お金（地代）、ロット（元の圃場）。
- **作業との関係:** 対象。面積は資材の量の計算に使う。

#### 4.3.2 水利

- **定義:** 圃場に水を入れたり出したりする仕組みと、その使い方の決まり。
- **1件の単位:** 取水口1か所、または水路の1区間。
- **主な属性:**
  - 名前、場所、水利組合（関係先）
  - 通水の期間（年度ごと）、共同作業の日（年度ごと）
  - 水利費（お金）
- **続く期間:** 年をまたいで続く。
- **関係:** 圃場（どこから水を引くか）、関係先、お金。
- **作業との関係:** 対象（W-16 水路の掃除）。前提条件（W-19 入水は通水が始まってから）。

#### 4.3.3 品種

- **定義:** 作る稲の種類。
- **1件の単位:** 1品種。
- **主な属性:**
  - 名前、早晩性、用途（主食用・酒米・飼料用など）
  - 標準の日数（播種から田植え、田植えから出穂、出穂から刈り取り）
  - 10a当たりの種籾の量と苗箱の数
- **続く期間:** 年をまたいで続く。
- **関係:** 作付、苗、ロット、資材（種籾は品種ごとの資材）。
- **作業との関係:** 作業の型の日数を、品種によって変える。対象（W-08〜W-13）。

#### 4.3.4 資材

- **定義:** 作業で使うと減るもの。
- **1件の単位:** 品目（商品）1つ。在庫は品目ごとの量で持つ。
- **主な属性:**
  - 共通：名前、種類（種籾・肥料・農薬・培土・堆肥・土壌改良剤・米袋・燃料）、単位、10a当たりの標準量、購入先（関係先）
  - 農薬：登録番号、成分、倍率、成分ごとの使用回数の上限、収穫前の使用禁止日数
  - 肥料：成分（窒素など）
- **続く期間:** 品目は年をまたいで続く。在庫も年をまたぐ（使い残しの肥料や農薬）。
- **状態:** 発注ごとに、発注済み → 入荷。
- **数量:** 在庫は「入った量 − 使った量」である。入るのは発注・購入（お金と結び付く）、使うのは作業の結果である。
- **関係:** 品種（種籾）、関係先、お金、作業の結果。
- **作業との関係:**
  - 対象（W-03 発注）
  - 前提条件（在庫が足りている。農薬の使用回数が上限に達していない）
  - 結果（使った量）

#### 4.3.5 機械

- **定義:** 作業に使う動力付きの機械。
- **1件の単位:** 1台。
- **主な属性:**
  - 名前、種類（トラクター、畦塗り機、田植機、防除機、草刈り機、コンバイン、乾燥機、籾摺り機など）
  - 能力（条数・作業幅・乾燥機の容量）
  - 所有（自分のもの・共同利用・借りるもの）、購入日
  - 使える作業の種類
- **続く期間:** 年をまたいで続き、手放すまで残す。
- **状態:** 使える・整備中・使えない。
- **取り合い:** 同じ時間には1つの作業にしか使えない。
- **関係:** お金（購入・修理・燃料）、関係先（修理先・共同利用の相手）、書類（修理の請求書）、ロット（乾燥機の1回分）。
- **作業との関係:** 対象（W-04 整備、W-47 格納）。前提条件（空いていて、使える状態である）。

#### 4.3.6 施設・設備

- **定義:** 動かない建物と、圃場などに据える設備。
- **1件の単位:** 1棟・1か所。
- **主な属性:**
  - 名前、種類（育苗ハウス・作業場・倉庫・電気柵）
  - 場所（電気柵は圃場）
  - 容量（ハウスに置ける苗箱の数、倉庫に置ける袋の数）
- **続く期間:** 年をまたいで続く。電気柵は設置と撤去で場所が変わる。
- **状態:** 使える・使えない。
- **取り合い:** 容量の範囲で、複数の苗やロットが共有する。
- **関係:** 苗（育苗場所）、ロット（保管場所）、圃場（電気柵）、お金。
- **作業との関係:** 対象（W-15 育苗管理、W-37 電気柵の設置）。前提条件（空きがある）。

#### 4.3.7 人

- **定義:** 作業をする人。
- **1件の単位:** 1人。
- **主な属性:**
  - 名前、立場（本人・家族・雇用・作業を頼む相手）、連絡先
  - 作業できる日、扱える機械と作業
  - 資格（大型特殊免許など）、賃金の決まり
- **続く期間:** 年をまたいで続く。
- **取り合い:** 同じ時間には1つの作業しかできない。
- **関係:** 機械（扱えるもの）、お金（人件費・委託料）、ISAS のアカウント（ログインする人だけ）。
- **作業との関係:** 担当。前提条件（手が空いている）。

#### 4.3.8 関係先

- **定義:** 経営の外にいて、取引・提出・共同作業の相手になる組織や人。
- **1件の単位:** 1組織・1人。
- **主な属性:**
  - 名前、連絡先
  - 種類（JA・検査所・資材の購入先・販売先・地主・水利組合・地域・共済・協議会・税務署・修理先）
  - 毎年の指定日と締切（年度ごと）
- **続く期間:** 年をまたいで続く。
- **関係:** お金（相手）、書類（提出先・発行元）、資材（購入先）、圃場（地主）、水利。
- **作業との関係:** 前提条件の「暦」（指定日・締切）。

### 4.4 流れ

#### 4.4.1 苗

- **定義:** 同じ品種を同じ日にまいて育てる苗のまとまり。
- **1件の単位:** 品種 × 播種日。
- **主な属性:**
  - 品種、播種日、箱数、苗の種類（稚苗・中苗）
  - 使った種籾（資材）、育苗場所（施設）
- **続く期間:** 4〜5月だけ。植え終わったら終わる。
- **状態:** 準備中 → 育苗中 → 植え終わり。
- **数量:** 箱数。田植えで、圃場ごとに使った箱数だけ減る。
- **関係:** 品種、資材、施設、作付（どの圃場に植えたか）。
- **作業との関係:**
  - 対象（W-14 播種、W-15 育苗管理、W-21 施薬）
  - 前提条件（W-22 田植えは、苗が適期で箱数が足りていること）

#### 4.4.2 収穫物のロット

- **定義:** 乾燥・調製・出荷を一緒に行う籾や米のまとまり。
- **1件の単位:** 乾燥機の1回分（籾のロット）。調製後は、袋詰めしたまとまり（米のロット）。途中で分けたり合わせたりする。
- **主な属性:**
  - 品種、元になった圃場またはロット（複数）、収穫日
  - 水分、重量、袋数、等級
  - 保管場所（施設）、出荷先（関係先）
- **続く期間:** 9月から出荷まで。ただし記録は、どの圃場の米かをたどるために、年度の締めのあとも残す。
- **状態:** 乾燥中 → 調製済み → 検査済み → 保管中 → 出荷済み。
- **数量:** 重量と袋数。出荷すると減る。
- **関係:** 作付と圃場（元）、機械（乾燥機）、施設、関係先、お金（販売代金）、書類（検査結果・出荷伝票）。
- **作業との関係:** 対象（W-41〜W-45）。結果（水分・重量・等級）。

### 4.5 記録

#### 4.5.1 気象

- **定義:** 作業の判断に使う天気の観測値と予報。
- **1件の単位:** 地点 × 日。
- **主な属性:** 日付、地点、気温（最高・最低・平均）、水温、降水量、予報。
- **続く期間:** 毎日たまる。年をまたいで比べるために残す。
- **関係:** 圃場（地点）、作付（積算の起点）。
- **作業との関係:** 前提条件（積算水温・積算気温・天候）。

#### 4.5.2 書類・記録

- **定義:** 出す書類・受け取る書類・保存する書類と、作業から生まれない記録。
- **1件の単位:** 1通（1件の申請、1枚の請求書）。
- **主な属性:**
  - 種類、年度、関係先（提出先・発行元）、締切
  - 元にした作業の結果（作業の結果から作る書類の場合）
  - ファイル、保存期限、関係するお金
- **続く期間:** 保存期限まで。帳簿と領収書には、法律で決まった保存期間がある。
- **状態:**
  - 出す書類：作成中 → 提出済み → 受理
  - 受け取る書類：受領
- **決まり:**
  - 作業でやったことや測った値は、作業の結果が正本である。書類・記録には書き写さない。
  - 書類・記録として持つのは、作業の結果から作る書類（どの結果から作ったかと、提出の状況を持つ）と、作業から生まれない記録（請求書・領収書、検査結果の通知、帳簿など）の2つである。
- **関係:** 関係先、お金、年度、作業の結果。
- **作業との関係:** 対象（作る・出す）。前提条件（記録がそろっている。締切）。

#### 4.5.3 お金

- **定義:** 経営に入るお金と出ていくお金の、1回ごとの記録。
- **1件の単位:** 1回の入金、または1回の支払い。
- **主な属性:**
  - 日付（入金日・支払日）、金額、区分（収入・支出）、費目
  - 相手（関係先・人）
  - 年度（どの年の米の分か。日付とは別に持つ）
  - 関係するリソース（資材・機械・圃場・ロット・人）、根拠の書類
- **種類の例:**
  - 収入：販売代金、JA の概算金と追加払い、交付金、共済金
  - 支出：資材費、機械の購入・修理・燃料、人件費、作業の委託料、水利費、地代、共済の掛金、検査の手数料
- **続く期間:** 年度の締めと申告のあとも、保存期限まで残す。
- **状態:** 見込み → 確定 → 入金済み・支払い済み。JA の概算金と、翌年の追加払いを分けて持つため。
- **関係:** 関係先、書類、資材、機械、圃場、ロット、人。
- **作業との関係:**
  - 結果（発注すると支出、出荷すると収入）
  - 前提条件（確定申告は、1年分がそろっていること）

### 4.6 リソースどうしのつながり

1. **生産物の流れ:** 種籾（資材）は苗になり、圃場で稲（作付）として育つ。稲刈りで籾のロットになり、調製した米のロットとして出荷され、お金になる。どの圃場の米かをたどれるよう、このつながりを年度の締めのあとも残す。
2. **作付が中心:** 「年度 × 圃場 × 品種」の作付が決まると、次のものが決まる。
   - 資材の必要量（面積 × 10a当たりの量）
   - 苗の箱数
   - 作業の日程（品種の標準の日数）
   - 作業の件数（圃場ごとに1件）
3. **お金はリソースに結び付く:** お金を圃場・ロット・資材・機械に結び付けると、圃場ごとや品種ごとの10a当たりの収支が出せる。これは翌年の作付計画（W-01・W-02）に使う。

| W-03 資材の発注 | 注文書、請求書・領収書 | 支出（資材費） |

### 4.8 管理方法を考えるための観点

| 観点 | 当てはまるリソース | 管理で必要になること |
|---|---|---|
| 年度ごとに作り直す | 作付。年度ごとの属性として、水利の通水期間、関係先の締切 | 前年の写しから作れること |
| 量が増減する | 資材（在庫）、苗（箱数）、ロット（重量・袋数）、お金 | 入りと出の記録から、残りを計算すること |
| 取り合いが起きる | 機械、施設・設備、人 | 作業の日時と照らして、重なりを見つけること |
| 状態の段階がある | 年度、作付、資材（発注）、苗、ロット、機械、施設・設備、書類・記録、お金 | 段階の移り変わりを、作業の完了と結び付けること |
| たどる必要がある | 種籾 → 苗 → 作付（圃場） → 籾ロット → 米ロット → 出荷 → お金 | 元と先のつながりを、年度の締めのあとも残すこと |

## 5. 作業とリソース以外の管理対象

作業（やること）とリソース（持っているもの・相手）のどちらにも当たらないが、作業やリソースに影響し、それ自体を記録して追う必要があるものが4つある。§4.1 と同じ観点で定義する。

### 5.1 一覧

| 管理対象 | 一言で | 主に影響する先 | 時期 |
|---|---|---|---|
| 作業（§3） | やること | — | 通年 |
| リソース（§4） | 持っているもの・相手 | — | 通年 |
| 出来事 | 起きたこと・見つけたこと | 作業の前提条件、結果、お金（共済） | 通年（5〜10月が多い） |
| 決まりと基準 | 守るべきこと | 作業の前提条件、書類 | 通年（年度ごとに見直し） |
| 契約・約束 | 取り決めたこと | 作業、お金、ロット | 年度をまたぐ |
| 利用者と権限 | システムを使う人と、その範囲 | すべての記録 | 通年 |

### 5.2 出来事

- **定義:** 予定せずに起きたこと、見つけたこと、外部から届いた知らせ。
- **1件の単位:** 1つの出来事（1回の発見、1件の被害、1回の故障、1通の知らせ）。
- **種類:**
  - 病害虫・雑草・欠株の発生
  - 鳥獣害
  - 気象の被害（台風・冠水・高温）
  - 機械・施設の故障
  - 作業中の事故、ヒヤリハット
  - 外部の知らせ（病害虫の発生予察、気象警報、JA からの連絡）
- **主な属性:** 日時、場所（圃場など）、種類、程度、写真、発生元（自分の観察か、外部の知らせか）、関係するリソース（圃場・機械・人）、それを受けて行った作業。
- **続く期間:** ずっと残す。翌年の計画と、共済の請求に使う。
- **状態:** 見つけた → 対応中 → 対応済み（または対応しない）。
- **関係:** 圃場、機械、施設・設備、人、関係先（知らせの発信元）、お金（共済金）、書類（被害の届け）。
- **作業との関係:**
  - 前提条件になる。例：W-23 補植は欠株があること、W-32 いもち病の防除は発生予察が出たか病斑があること。
  - 作業を生む。例：機械の故障から修理の作業。
  - 結果に影響する。例：被害による収量の減少。W-01 振り返りに使う。
- **作業の結果との分け方:** 生育調査（W-28）のように、予定した作業で観察した値は、作業の結果である。出来事は、予定の外で起きたこと・見つけたことに限る。
- **今の ISAS:** メモ（写真付きの記録）が近い使われ方をしているが、種類・程度・作業とのつながりはない。

### 5.3 決まりと基準

- **定義:** 外部が定め、作業やその結果が守るべき決まり。
- **1件の単位:** 1つの決まり（1つの基準、要件、点検項目）。
- **種類と例:**
  - 農薬の使用基準（登録された作物・倍率・使用回数・収穫前の使用禁止日数）
  - 特別栽培の基準（化学肥料の窒素量と農薬の成分回数を、地域の慣行の5割以下に抑える）
  - GAP の点検項目
  - 交付金の要件（用途・面積）
  - 地域の防除暦、水利の決まり
- **主な属性:** 名前、定めた所（関係先）、版と有効期間、当てはまる範囲（作物・資材・作業の型・作付）、決まりの中身（上限・期限・残すべき記録）、確かめ方（1回ごとか、1年分の合計か）。
- **続く期間:** 版ごとに残す。改定されたら新しい版を作り、過去の年度は当時の版で確かめる。
- **関係:** 資材（農薬の登録内容）、作付（栽培方法・用途）、関係先、書類（申請・生産記録）。
- **作業との関係:**
  - 前提条件と確認に使う。例：この農薬は、この作付であと1回しか使えない。窒素量の合計が上限に近い。
  - 書類（生産記録、認証や交付金の申請）を作るときの基準になる。
- **資材の属性との分け方:** 1つの資材に付く値（農薬の倍率など）は、資材の属性（§4.3.4）に持てる。複数の作業や1年分の合計にかかる決まりと、年度・版で変わる決まりは、こちらで持つ。
- **今の ISAS:** なし。

### 5.4 契約・約束

- **定義:** 関係先と取り決めた、期間・数量・期限のある約束。
- **1件の単位:** 1つの取り決め。
- **種類と例:**
  - 出荷・販売：JA との出荷契約（数量）、直売や知り合いからの注文
  - 土地：借地契約（期間・地代・更新）
  - 作業：作業の受託・委託（ほかの家の田を刈る、刈ってもらう）
  - 機械：共同利用の取り決め
  - 人：雇用契約
- **主な属性:** 種類、相手（関係先・人）、期間（開始・終了・更新）、数量と単位、金額や単価、期限（納期・支払日）、対象のリソース（圃場・機械・品種など）、根拠の書類。
- **続く期間:** 取り決めの期間。年度をまたぐことがある（借地は数年単位）。終わった取り決めも残す。
- **状態:** 交渉中 → 有効 → 終了（または解約）。
- **関係:** 関係先、人、圃場（借地、受託した田）、機械、ロット（出荷数量）、お金（支払い・入金の予定）、書類（契約書）。
- **作業との関係:**
  - 作業を生む。例：受託した稲刈り、注文の出荷。
  - 前提条件の「暦」になる。例：納期、支払日。
  - リソースを縛る。例：出荷契約の数量に対して、ロットが足りているか。
- **注意:** 作業を受託すると、ほかの人の圃場が作業の対象になる（Q-20）。
- **今の ISAS:** なし。

### 5.5 利用者と権限

- **定義:** ISAS を使う人と、その人が見られる・直せる範囲、および変更の履歴。
- **1件の単位:** 利用者は1アカウント、権限は1つの役割、履歴は1回の変更。
- **主な属性:**
  - 利用者：ログインの情報、言語、対応する人（§4.3.7）
  - 役割：名前（例：経営者・家族・雇用・閲覧だけの関係先）と、役割ごとに見られる範囲・直せる範囲
  - 履歴：いつ、誰が、何を、どう変えたか
- **続く期間:** 利用者と役割は通年。履歴は、記録の保存期限まで残す。
- **状態:** 利用者は、招待中 → 有効 → 取消し。
- **関係:** 人（作業をする人との対応）、関係先（例：JA の担当者に生産記録だけを見せる）、すべての記録（履歴）。
- **作業との関係:**
  - 担当の人がログインするなら、自分の作業を見て記録する。
  - 結果と書類の正しさを、誰がいつ記録したかで示す（GAP で問われる）。
- **人との違い:** 人（§4.3.7）は作業をする人、利用者はシステムを使う人である。ログインしない作業者もいれば、作業しない利用者（事務担当、管理者）もいる。
- **今の ISAS:** 利用者・管理者・招待・取消し・関係（他人の圃場の見え方）がある。役割による権限の違いと、変更の履歴はない。

### 5.6 既存の定義に属性を足せば済むもの

次は独立した管理対象にせず、既存の定義で持つ。

| 候補 | 持つ場所 | 理由 |
|---|---|---|
| 目標・予算 | 年度の予算（§4.2.1）、作付の目標（§4.2.2） | 前提条件の「茎数が目標の約8割」で目標値が要るが、作付ごとの値として持てる |
| 判断の理由 | 結果の「決めたこと」（§3.2.7）、状態「不要」の理由（§3.3.2） | 何をなぜ決めたかは、その作業に付けば足りる |
| 評価・集計（収量・収支・作業時間） | 持たない。結果とお金から計算する | 別に持つと、元の記録と食い違う |
| 連絡・共有（メモ・指示） | 今の ISAS にある（§6.5、Q-16） | 新しく作る対象ではない |

| Excel 出力 | 書類（生産記録など）の出力として検討する |

### 6.7 データ基盤の課題

[レビュー記録票_第2版_日次タスク管理.md](レビュー記録票_第2版_日次タスク管理.md) の R-13 のとおり、現状は通常の接続で外部キーが効いておらず、複数の書き込みをまとめるトランザクションもない。型から作業を一括で作る、起点が決まったら後の作業をまとめてずらす、といった処理は多くの行を一度に書き込むため、第3版の前に直す必要がある。

## 7. 決めていないこと

| No | 論点 | 内容 |
|---|---|---|
| Q-01 | 対象の範囲 | 地域・規模・作型をどこまで扱うか。直播を含めるか。米以外の作物を扱うか |
| Q-02 | 作業の単位の移行 | 今のガント作業は1件に複数の圃場を付けられる。対象ごとに1件とする定義（§3.2.5）に、既存の作業をどう移すか |
| Q-03 | 予定と塗りの原則 | 「田植えの塗りが済んだら田植日を結果にする」のように塗りと作業をつなぐと、第1版からの原則「予定と塗りは自動で同期しない」を変えることになる |
| Q-04 | 第2版で対象外にしたもの | スマホでの記録・担当・繰り返し・通知を、第3版の対象に入れるか |
| Q-05 | 結果と完了の関係 | 結果を残さないと完了にできないようにするか（例：出穂日がないと出穂の確認を完了にできない） |
| Q-06 | 前提条件の判断 | 観測値による条件をシステムが判断するか、人が確認して印を付けるか |
| Q-07 | 担当を持つか | 想定する経営の人数で決まる |
| Q-08 | 苗箱の扱い | 苗箱は毎年使い回すので、使うと減る資材より施設・設備に近い。どちらで持つか |
| Q-09 | 人とアカウント | ログインしない人も管理するか。人とアカウントをどう結び付けるか |
| Q-10 | 気象の取り方 | 手で入れるか、外部のデータ（気象庁など）を取り込むか |
| Q-11 | お金の範囲 | 作業と収支の判断に要る範囲（金額・費目・相手・関係するリソース）だけ持ち、帳簿は会計ソフトに任せるか。帳簿まで ISAS で持つか |
| Q-12 | お金の割り振り | 1回の支出（例：肥料をまとめて買った）を、複数の圃場に割り振るか |
| Q-13 | 書類の保存期限 | 法律で決まった保存期間を過ぎた書類を、システムで管理するか |
| Q-14 | 終わった台帳の扱い | 使わなくなった圃場・機械・品種を、消さずに「使わない」状態にするか |
| Q-15 | 年度の期間 | 年度をいつからいつまでとするか（例：12月〜翌12月）。前後の年度が重なる時期の扱い |
| Q-16 | ISAS にだけあるものの位置づけ | §6.5 の題名・作業名・塗り・指示・メモなどを、§3〜§5 の定義とどう対応させるか |
| Q-17 | 進め方 | 本書をもとに第3版の要求仕様書を起こすか。データ基盤の課題（§6.7）をいつ直すか |
| Q-18 | 出来事とメモ | 出来事を、今のメモ（写真・タグ）を広げて持つか、別に持つか |
| Q-19 | 決まりと基準の入れ方 | 農薬の登録内容などを手で入れるか、外部のデータを取り込むか。どの基準（特別栽培・GAP など）を扱うか |
| Q-20 | 受託した作業の対象 | ほかの人の圃場を作業の対象にするとき、今の「関係（他人の圃場の見え方）」とどう合わせるか |
| Q-21 | 権限の役割 | どんな役割を用意するか。関係先（JA の担当者など）にもログインさせるか |
| Q-22 | 変更の履歴 | すべての記録の変更履歴を残すか、結果と書類だけにするか |

## 8. 用語

| 用語 | 意味 |
|---|---|
| 型 | 毎年ほぼ同じ作業の決まり。栽培暦の1行に当たる |
| 作業 | 型を、ある年度のある対象に当てはめた1件 |
| 栽培暦 | 品種・作型ごとの、1年の標準の作業の並び |
| 起点 | 日時を決める元になる日。田植日・出穂日など |
| 適期 | 作業をすればよい期間。いつからいつまで |
| 遅れ | 適期の終わりを過ぎても、完了・不要のどちらにもなっていない作業 |
| リソース | 作業以外に管理するもの。作業の対象・前提条件・結果・担当から参照される |
| 作付 | ある年度に、ある圃場で、どの品種をどう作るかの決定 |
| 作型 | 作り方の型。苗を植える移植と、種を田に直接まく直播など |
| ロット | 乾燥・調製・出荷を一緒に行う籾や米のまとまり |
| 積算水温・積算気温 | 毎日の平均の水温・気温を足し合わせた値。浸種や刈り取りの目安に使う |
| 出穂 | 稲の穂が出ること。出穂日は後の多くの作業の起点になる |
| 穂肥 | 出穂の前に与える追加の肥料 |
| 中干し | 生育の途中で田の水を抜き、土を乾かすこと |
| 落水 | 収穫に向けて田の水を抜くこと |
| 出来事 | 予定せずに起きたこと、見つけたこと、外部から届いた知らせ。病害虫の発生、被害、故障、発生予察など |
| 決まりと基準 | 外部が定め、作業やその結果が守るべき決まり。農薬の使用基準、特別栽培の基準、GAP の点検項目など |
| 契約・約束 | 関係先と取り決めた、期間・数量・期限のある約束。出荷契約、借地契約、作業の受託など |
| 利用者 | ISAS にログインして使う人。作業をする「人」とは別に扱う |
| 役割 | 利用者ごとに、見られる範囲・直せる範囲を決めるまとまり |
