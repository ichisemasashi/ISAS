## 3. 処理の規則

| 項番 | 出典 | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| P4-3.1-01 | 圃場1枚以上の利用者だけ | 画面 | 0枚になる | ガントは開けない。行は消さない。再び1枚以上なら残っている行を使える |
| P4-3.1-02 | 対象は自分の圃場だけ | API | 他人の field_id | 付けられない |
| P4-3.2-01 | 題名必須。前後空白を除く | API | 空白だけ | 空にはできない |
| P4-3.2-02 | 開始と終了必須。分まで。秒は持たない | API | 秒付き | 分まで |
| P4-3.2-03 | 同じ時刻は不可 | API | 開始＝終了 | 保存しない |
| P4-3.2-04 | 対象がある行は作業名必須 | API | 対象あり・作業名空 | 保存しない |
| P4-3.2-05 | 対象を全部外した行 | API | 作業名が残る | ラベル付きメモとしてよい |
| P4-3.2-06 | 同じ時間帯に複数行 | API | 重なる2行 | 置ける |
| P4-3.2-07 | 新規の初期値 | 画面 | 行を足す操作 | 題名「新しい予定」、開始＝今日 08:00、終了＝今日 17:00、作業名なし、対象なし、としてよい |
| P4-3.3-01 | 選択中の1行だけ | 画面 | 複数行 | まとめた％は出さない。計算しない |
| P4-3.3-02 | 分母は対象面積の合計㎡ | API | 2枚 | 枚数ではない |
| P4-3.3-03 | 分子は工程3の塗り面積 | API | 塗ったあと progress | 圃場ごとに圃場面積を超えない。合計 |
| P4-3.3-04 | 整数％ | 画面・API | `floor(100 * 分子 / 分母)` | 対象がすべて `done` のときだけ 100。すべて `done` でないのに `floor` が 100 になる場合は 99（整数㎡と done 判定の差の上限）。通常の一部塗りは 0〜99 の `floor` 値。分母0は起きない |
| P4-3.3-05 | 日誌％・手入力 | 禁止 | `/gantt` | サークルを上書きする欄は無い |
| P4-3.3-06 | 全面完了の場所 | 禁止 | `/gantt` | 塗り・全面完了は `/map`（工程3）。ガントでは％と色を見るだけ |
| P4-3.3-07 | 保存ボタン | 画面 | 編集欄 | `time_order` または `work_name_required` になる入力では保存を押せない。予定を足すも時刻不正では押せない |
| P4-3.4-01 | 対象付き行を選んでいる | 画面 | 対象1枚以上かつ作業名あり | 対象は工程3の未／一部／済。対象でない自分の圃場は `#e8e8e8`。地図側の作業名選択はこのあいだ使わない |
| P4-3.4-02 | 未選択・メモ行・対象0 | 画面 | それらを選ぶ | 工程3どおり。地図側で作業名を選べば全自分圃場にその塗り色。選ばなければ形だけ |
| P4-3.5-01 | 候補の和集合 | API | 塗りとガント | 文字順。塗りが無くなりガントにも残っていない名前は消える。工程5の指示名はこの工程では足さない |

日時の保存は日本時間 `YYYY-MM-DDTHH:MM`（タイムゾーン文字列は付けない）。作成・更新の記録時刻は UTC。
