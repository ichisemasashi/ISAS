# ISAS 使い方　利用者向け

- 対象: 招待された利用者アカウント
- 入口: `/`（利用者ログイン）
- 関連: [管理者向け](使い方_管理者.md)、[使い方（目次）](使い方.md)、[要求仕様書.md](要求仕様書.md)、[要求仕様書_第2版.md](要求仕様書_第2版.md)

パソコンが主です。スマホでは **メモ**・**日次一覧の閲覧**・**指示の進捗と日誌** が中心です。作業・ガント・地図の編集や指示の作成はパソコンで行います。

画面の見出しやボタンは「言語」で日本語／English に切り替えられます（圃場名・作業名・依頼文・日誌・メモ本文などの入力内容は翻訳されません）。

用語は末尾の **用語集** を参照してください。

---

## 1. はじめに

| できること | 主な画面 |
|---|---|
| 自分の圃場を持つ・直す・塗る | 圃場台帳、地図 |
| 予定を持つ・実行状態を回す | 作業、ガント、日次一覧 |
| 短い記録を共有する | メモ |
| 他人へ作業を依頼する／受ける | 指示、日誌 |
| 一度対象になった相手の圃場の進捗を見る | 他人の対象圃場 |

- 公開登録はありません。招待されたメールアドレスで入ります。
- 管理者入口（`/admin`）には、利用者のパスワードでは入れません。
- 圃場が 0 枚でもログイン・メモ・指示の受け取り・日誌・スマホでの日次閲覧はできます。塗り・作業・ガント・指示の作成は、圃場が 1 枚以上あるときだけです。

### パソコンとスマホ

画面の幅が狭い（おおよそスマホ）と、次のようになります。

| 画面 | スマホ |
|---|---|
| 圃場台帳・地図・作業場所・下地 | 不可（パソコンで。入口なし） |
| 作業・ガント | 不可（パソコンで。入口なし） |
| 指示を出す・直す・閉じる | 不可（パソコンで。入口なし） |
| 他人の対象圃場のまとめ | 不可（パソコンで。入口なし） |
| 日次一覧 | **閲覧可**（実行状態は変えられない） |
| メモ（投稿・検索・紐づけなど） | **可** |
| 指示一覧・指示の進捗閲覧・日誌 | 可 |
| ログイン・招待・パスワード・言語 | 可 |

---

## 2. ログイン・パスワード・ログアウト

1. `/` を開き、メールアドレスとパスワードを入れて「入る」。
2. 忘れたとき: 「パスワードを忘れた」→ メールを入れて「案内を送る」→ 届いた案内から新しいパスワードを「決める」（8 文字以上）。
3. ログイン後に変える: ナビの「パスワード」→ 今の／新しい／確認 →「変える」。
4. 「ログアウト」で出ます。

利用者と管理者は入口が別です。案内メールを送る入口を間違えないでください。

---

## 3. ホームとナビ

### パソコン幅のナビ

言語｜ホーム｜日次｜作業｜ガント｜圃場台帳｜地図｜メモ｜指示｜招待｜パスワード｜ログアウト

### 狭い画面

- 上部ナビ: 言語｜ホーム｜指示｜招待｜パスワード｜ログアウト（使えない入口は出しません）
- **下部ナビ**: メモ｜日次｜指示（ホーム／メモ系では「メモ」、日次では「日次」、指示では「指示」が現在位置）

### ホームからの出口

- **狭い画面**: メモのタイムライン、「続きを読み込む」、「メモの投稿・検索」
- **パソコン幅・圃場が 1 枚以上**: 「日次一覧」「作業」「ガント」「指示を出す」
- **パソコン幅**: 「指示」「他人の対象圃場」「メモ」（共有メモのタイムライン）

---

## 4. 利用者を招待する

1. 「招待」を開く。
2. 相手のメールアドレスを入れて「招待する」。
3. 画面に出る「初期パスワード」を相手に伝えます（この画面を離れると同じ文字列は再び出せません）。
4. 相手は利用者入口から、そのメールと初期パスワードで入ります。

すでに利用者として招待済みのメールや、管理者のメールは招待できません。招待の取消しは管理者の仕事です。

---

## 5. 作業場所と下地（パソコン）

地図を初めて使うときは、先に作業場所の範囲を決めます。

1. 「地図」→ 作業場所の画面へ進む（未設定なら自動で案内されます）。
2. 地理院地図を動かして範囲を決める。
3. 「空中写真で最終確認」で見たあと、「この範囲を作業場所にする」。直すなら「地理院地図に戻って範囲を直す」。
4. 保存中は「作業場所を保存し、下地を取り込んでいます…」と出ます。完了まで待ちます。

あとから変えるときは地図の「作業場所を変える」から同じ流れです。

### 下地

地図の操作で「下地」を選びます。

- 「この範囲の下地を自動で取り込む」
- 手でファイルを入れる種類: 空中写真／標準地図／衛星
- 位置の微調整（西東南北・縮小拡大など）のあと「下地の位置を保存」
- 「下地の種類」で、取り込んだ下地を切り替え

初期の表示は、作業場所の空中写真を想定しています。

---

## 6. 圃場台帳（パソコン）

「圃場台帳」で、自分の圃場の一覧を見ます。

- 名前・ha・㎡・メモを直して「保存」（いつでも直せます）
- 形から出した面積が初期値です。台帳で直した ha／㎡は台帳の表示用です（塗りの％の分母はこれまでどおり形の面積です）
- 「削除」で消す（ガントの対象や指示の対象からは外れます。ガント行や指示そのものは残ります）
- 「地図へ」で地図画面へ

名前の重複は許されます。形の編集は地図側です。

---

## 7. 地図で圃場の形を作る・直す（パソコン）

地図の「操作」から選びます。

| 操作 | やること |
|---|---|
| 手描き | 閉じた多角形を描き、名前を付けて「圃場を保存」 |
| 修正 | 頂点を動かして「形と名前を保存」 |
| 分割 | 圃場を選んで切り線を引き「分割を保存」（塗りが残っているとできないことがあります） |
| 合筆 | 残す圃場と他の圃場を選んで「合筆する」（塗りが残っているとできないことがあります） |
| 区画取込 | GeoJSON などを取り込む |

「やめる」で操作をやめます。

---

## 8. 作業名と塗り（パソコン）

実績の正本は地図の塗りです。画面は上から順に分かれています。

1. 作業名を入れ、「この作業名で見る」（メニューからでも、塗りからでも可）。
2. **塗る**: 「ブラシ」でなぞる →「塗りを確定する」。やめるなら「下書きを捨てる」。確定と破棄は下書きがあるときだけ押せます。
3. **選んだ圃場**: 地図で圃場をクリックしてから「全面完了」や「この作業名の塗りを全部消す」。
4. **選んだ塗り**: 地図で塗りをクリックしてから「この塗りを消す」。
5. **ほか**: 「圃場を直す」「下地」へ。

色の目安: 未／一部／済。

- 「田植え」と「田植」は別の作業名です（完全一致）。
- 他人の圃場は見えても塗れません。自分の圃場だけです。
- ガントや指示が無くても、塗りだけで実績になります。
- 塗り・作業・ガント・指示で一度使った名前は、どの画面の作業名入力でも候補から選べます。

---

## 9. 作業（パソコン・圃場が 1 枚以上）

題名やガント画面とは別に、作業そのものを管理します。

1. 「作業」を開く（ナビまたはホーム）。
2. **「1. 作業を選ぶ」**で、編集したい作業の「編集する: …」ボタンを押す（押すまで下に編集欄は出ません）。
3. **「2. 基本情報を直す」**で作業タイトル・時刻・実行状態・作業名・対象圃場などを直し「基本情報を保存」。
4. 同じ画面の **「3. 作業時間とチェック項目」**で明細を足します。
   - **作業時間**: 「新しい作業時間を追加」で開始・終了を入れて「この時間を追加」。複数可。親の予定の外や重なりも可。
   - **チェック項目**: 「新しいチェック項目を追加」で項目名を入れて「この項目を追加」。状態（まだ／やった）は選ぶとすぐ保存。項目名の変更は「項目名を保存」。
5. 一番下の **「新しい作業を登録」**から、まだ無い作業を作ります（作業タイトル・開始・終了・任意の作業名。作業名を空にすると作業タイトルが作業名候補にも入ります。作った直後は上の一覧から選び直して明細を足します）。
6. 作業を選んだあと、**「4. 一覧から消す（ソフト削除）」**で消します（確認あり）。付いていた作業時間・チェックも通常の一覧からは見えなくなります。メモに紐づいていた場合は、メモのスレッドに「紐づいた作業: …（削除済み）」と出ます。

注意:

- **作業タイトル（表示名）**は一覧やガントの棒に出る名前です。題名（グループ）や塗り用の**作業名**とは別です。
- 対象圃場がある作業は、作業名が必須です。
- 塗り・作業・ガント・指示で一度使った名前は、どの画面の作業名入力でも候補から選べます（表示名も候補に入ります）。
- 作業時間やチェックを変えても、実行状態・塗り・面積％は自動では変わりません。
- ガントの棒グラフ表示は「ガント」画面で、題名を選んで行います。題名のない作業はガントの題名配下には出ません。

---

## 10. 日次一覧

今日／今週／先週／前後7日／すべての予定を、実行状態で見る一覧です。終わっていない遅れた作業も出ます。

1. 「日次」（ナビ・ホーム、またはスマホの下部ナビ）を開く。開いた直後は前後7日・未着手＋着手中。
2. 期間と状態フィルタを変え「絞り込む」。
3. **パソコン**: 各行で実行状態を選んで保存。作業時間の件数とチェック進捗（やった数／総数）の要約が見えます。詳しい編集は「作業を開く」から。
4. **スマホ**: 同じ期間・状態で**閲覧だけ**できます。「スマホでは状態を変えられません」。作業の編集リンクは出ません。

期間の意味:

| 期間 | 出る作業 |
|---|---|
| 今日 | 今日にかかる作業 |
| 今週 | 月曜から日曜までにかかる作業 |
| 先週 | 先週の月曜から日曜までにかかる作業 |
| 前後7日 | 7日前から7日後まで（今日を含む15日）にかかる作業 |
| すべて | 期間で絞らない |

注意:

- **遅れ**: 終了日時を過ぎても完了になっていない作業には、赤い「遅れ」が付きます。今日・今週・前後7日では、期間より前に終わった遅れの作業も一覧の先頭側に出ます。完了にするか、作業画面で「一覧から消す」まで出続けます。
- 日次一覧で状態を保存しても、作業タイトル・開始／終了・対象などは変わりません。
- 作業画面で保存したとき「ほかの画面でこの作業が変更されています」と出たら、別のタブや日次一覧で先に変更されています。最新の内容が読み込み直されるので、確認してからもう一度保存してください。
- パソコンでは圃場が 1 枚以上あるときだけ使えます。スマホでは圃場 0 枚でも自分の作業を閲覧できます。
- 作業時間が無い行は「作業時間なし」、チェックが無い行は「チェックなし」と出ます。

---

## 11. ガント（パソコン・圃場が 1 枚以上）

自分用の予定を題名ごとに時間軸で見る画面です。進捗％と地図もここで確認します。指示とは自動ではつながりません。作業の追加・編集は「作業」画面でもできます。

1. 「ガント」を開く。見出し下の案内どおり、まず題名を選ぶ（または足す）。
2. 「1. 題名を選ぶ」で題名を選ぶ。まだ無ければ「題名を足す」。
3. 「2. 作業を選ぶ」で棒または「編集する: …」を押す（押すまで編集・明細は出ません）。
4. 「3. 基本情報を直す」と、その下の「作業時間とチェック項目」で直す（作業画面と同じ）。
5. 「この題名に作業を登録」で新しい作業を足す（開始・終了は分までの日時。初期は今日 08:00〜17:00。任意で作業名）。
6. 「時間の範囲」と「向き」で軸の見え方を変える。
7. 選んだ作業の **「4. 一覧から消す（ソフト削除）」**で消す（確認あり）。メモに紐づいていた場合はスレッドに「削除済み」と出ます。

注意:

- 「振り返り」で、その作業の日付ごとの確定％を見られます（適用外の日は「—」）。
- ログインやガントを開いたとき、東京時間の前日までの未確定分が自動で確定されます。
- 対象圃場がある作業は、作業名が必須です。
- 対象も作業名も無い作業、作業名だけの作業はメモで、パーセントは出ません。
- 対象と作業名がある作業を選ぶと、パーセントサークルと地図色が出ます（分母は対象面積、分子はその作業名の塗り）。
- 対象に付けられるのは自分の圃場だけです。
- 作業名の候補は作業画面と同じく、塗り・作業・ガント・指示で使った名前です。

---

## 12. メモ（パソコン・スマホ）

招待された利用者と管理者が、短い記録を時系列で共有します。塗り・％・実行状態・指示／日誌とは自動では連動しません。

### 入口

- パソコン: ナビの「メモ」、またはホームの「メモ」
- スマホ: 下部ナビの「メモ」（ホームのタイムライン）、または「メモの投稿・検索」

サブナビ: **タイムライン**｜**下書き**｜**ブックマーク**

### 投稿する

1. 「投稿」で本文を入れる（2000 文字以内）。
2. 任意でタグ（改行またはカンマ区切り、最大 20）、リンク（1 行に 1 つ、`http://` または `https://`、最大 20）。
3. 「公開する」または「下書き保存」を選んで「保存」。
4. 添付は、下書き保存または公開の**あと**に「ファイルを選ぶ」で追加します（最大 20。編集できるあいだは「添付を外す」可）。

### 下書き・公開・編集・削除

- **下書き**: 本人だけが見られます。一覧から編集して「保存」／「公開する」／「削除」。
- **公開後の編集**: 最後に保存した時刻から **30 分以内**だけ直せます（保存のたびに期限が延びます）。画面に「編集期限」が出ます。期限後は「編集できる期限を過ぎています」となり、直せません（ソフト削除して作り直します）。
- **削除**: 作成者（または管理者）が「削除」。子孫の返信も通常の一覧から消えます。

### 返信・検索・ブックマーク

- スレッドで「スレッドを開く」→「返信」。公開／下書きを選べます。
- 「検索」／「この条件で検索」。高度な条件（除外語・開始日・終了日・作成者メール）は「高度な条件を開く」。やめるときは「検索をやめる」。
- ★／☆でブックマーク。外すのは付けた本人だけです。「ブックマーク」一覧で見られます。

### 作業との紐づけ（公開済みの親のみ）

1. 公開済み親メモのスレッドを開く。
2. 作成者は「作業を選ぶ」→「作業を紐づける」（候補は作業／ガントで登録した自分の作業）。
3. 紐づくと、スレッド内に **「紐づいた作業: …」** と出ます（これが要約表示。別の「要約」欄はありません）。
4. 「紐づけを外す」／「別の作業に付け替える」ができます。
5. 作業側で「一覧から消す」と、同じ場所に **「（削除済み）」** が付きます。
6. 下書きや返信には作業を付けられません。

## 13. 指示を出す・直す・閉じる（パソコン・圃場が 1 枚以上）

1. 「指示を出す」（またはホームのリンク）。
2. 日付、開始・終了（同じ日）、作業名、依頼文、受け手のメール、対象圃場（自分の圃場）を入れて「指示を保存」。
3. 自分自身は受け手に含められません。
4. 「指示」一覧の「出した指示」から詳細を開く。
5. 進行中のうち、依頼文と時刻だけ直せます。受け手と対象圃場は変えられません。
6. 終わったら「この指示を閉じる」。閉じた指示は再開しません。日誌が無くても閉じられます。

---

## 14. 指示を見る・日誌を書く（スマホでも可）

1. 「指示」を開く（スマホは下部ナビからも可）。画面上の案内どおり、日誌は **「受けた指示」** を開いた詳細でのみ書けます（出した指示では書けません）。
2. 「受けた指示」の一覧には、進行中なら **「日誌未記入」／「日誌済」** の印が出ます。
3. 一件を開くと、依頼内容と対象圃場の進捗（色）が見えます。
4. 受け手で、まだ閉じておらず日誌を書いていないとき: 詳細の「日誌」欄に本文を入れ **「日誌を投稿する」**。
5. 日誌は指示 1 件につき受け手 1 人 1 通です。書いたら直せません。閉じたあとは書けません。

スマホでは、指示の作成・修正・閉じはできません（パソコンで）。閲覧と日誌はできます。

---

## 15. 他人の対象圃場（パソコン）

一度でも指示の対象になった相手の圃場だけが見えます（載っていなかった枚は見えません）。

1. 「他人の対象圃場」を開く。
2. 作業名を選んで「この作業名で見る」。
3. 地図の色と、所有者メール付きの一覧で進捗を確認します。

ここから塗ることはできません。相手との見え方を消す「関係を切る」は管理者だけが行います。

---

## 16. よくある制限

| 状況 | 結果 |
|---|---|
| 圃場が 0 枚 | 塗り・作業・ガント・指示作成は不可。メモ・指示の受け取り・日誌・スマホの日次閲覧は可 |
| スマホ幅 | 台帳・地図・作業・ガント編集・指示作成／閉じ・他人のまとめは不可。メモ・日次閲覧・指示閲覧／日誌は可 |
| 言語切替 | 画面文言だけ。入力した圃場名・作業名・日誌・メモなどはそのまま |
| 関係の切断 | 利用者画面には無い（管理者へ依頼） |
| ガントと指示 | 自動ではつながらない。別々の予定 |
| メモと塗り／％／実行状態 | 紐づけても自動同期しない |

---

## 17. 典型的な流れ

### 一人で使う

1. 招待されてログインする（必要ならパスワードを変える）。
2. 作業場所を決め、下地を取り込む。
3. 地図で圃場を手描き（または取込）し、台帳で名前を整える。
4. 作業名を付けて地図を塗り、進捗色を見る。
5. 必要なら作業／ガントに予定を置き、日次で実行状態を回す。対象付き行で％を見る。
6. 気づきはメモに残し、必要なら作業と紐づける。
7. 他人に頼むときは指示を出し、相手の日誌と塗りを待つ。自分で閉じる。

### スマホで助っ人として

1. 下部ナビの「指示」で受けた指示を開き、進捗色を見る。必要なら日誌を投稿する。
2. 「メモ」で共有メモを読む／書く。
3. 「日次」で自分の予定を閲覧する（状態は変えない）。

---

## 用語集

操作でよく出る語です。[使い方.md](使い方.md) の共通用語集と同じ内容です。

| 用語 | 意味 |
|---|---|
| 利用者 | 招待された営農用アカウント。入口は `/`。圃場や地図・指示などを使う |
| 管理者 | 運用用アカウント。入口は `/admin`。招待の取消し・関係の切断などが主な仕事。圃場は持たない |
| 招待 | メールアドレスを登録し、初期パスワードを一度だけ画面に出すこと。公開登録はない |
| 取消し | 管理者が利用者の招待を無効にし、ログインできなくすること |
| 初期パスワード | 招待直後に一度だけ表示される仮パスワード。画面を離れると同じ文字列は再表示できない |
| 圃場 | 利用者ごとの区画。台帳と地図の形で管理する |
| 作業場所 | 地図の対象範囲。下地取込の基準になる |
| 下地 | 作業場所に重ねる背景画像（空中写真・標準地図・衛星など） |
| 作業名 | 塗り・進捗％・指示などで一致キーになる名前。完全一致（「田植え」と「田植」は別） |
| 作業タイトル（表示名） | 作業一覧やガントの棒に出る名前。題名や作業名とは別 |
| 題名 | ガント上で作業をまとめるグループ名 |
| 作業 | 開始・終了などを持つ予定行。作業画面／ガントで管理する |
| 実行状態 | 作業の進捗段階。未着手／着手中／完了 |
| 日次一覧 | 今日・今週・先週・前後7日・すべてで作業を実行状態つきで見る一覧 |
| 遅れ | 終了日時を過ぎても完了になっていない作業。日次一覧で赤い「遅れ」が付く |
| 作業時間 | 作業に付けた実際の時間帯の明細 |
| チェック項目 | 作業に付けたやることリスト（まだ／やった） |
| ソフト削除 | 一覧から消すが履歴は残す削除。作業の「一覧から消す」、メモの「削除」など |
| 塗り | 地図上で作業名ごとに塗った実績。進捗色（未／一部／済）の正本 |
| パーセント（％） | 対象圃場の面積に対する、その作業名の塗り面積の割合 |
| 指示 | 他人への依頼票。日付・時刻・作業名・受け手・対象圃場を持つ |
| 受け手／出した人 | 指示を受け取った人／出した人 |
| 日誌 | 受け手が指示に対して書く「やった」記録。1人1通。訂正不可 |
| 関係の切断 | 管理者が二人のあいだの見え方をやめる操作。指示・日誌の記録は残る |
| メモ | 招待メンバと管理者が共有する短い時系列の記録（タイムライン） |
| 親メモ／返信 | スレッドの起点となる投稿／その下の返信 |
| 下書き | 本人だけが見られる未公開メモ |
| 編集窓 | 公開後、最後の保存から30分以内だけ本文などを直せる期間（保存のたびに延長） |
| 紐づいた作業 | 公開親メモに任意で付けたガント作業の要約表示。別欄の「要約」はない |
| 進捗確定 | 管理者が日付ごとのガント進捗％を確定する操作。利用者のログイン時にも前日分は自動確定される |
| 狭い画面（スマホ幅） | おおよそスマホ相当の幅。編集系の入口を隠し、下部ナビ（メモ／日次／指示）を出す |
