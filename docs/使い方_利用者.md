# ISAS 使い方　利用者向け

- 対象: 招待された利用者アカウント
- 入口: `/`（利用者ログイン）
- 関連: [管理者向け](使い方_管理者.md)、[要求仕様書.md](要求仕様書.md)

パソコンが主です。スマホは進捗の閲覧と日誌が中心です。画面の見出しやボタンは「言語」で日本語／English に切り替えられます（圃場名・作業名・依頼文・日誌などの入力内容は翻訳されません）。

---

## 1. はじめに

| できること | 主な画面 |
|---|---|
| 自分の圃場を持つ・直す・塗る | 圃場台帳、地図 |
| 自分用の予定を時刻つきで持つ | ガント |
| 他人へ作業を依頼する／受ける | 指示、日誌 |
| 一度対象になった相手の圃場の進捗を見る | 他人の対象圃場 |

- 公開登録はありません。招待されたメールアドレスで入ります。
- 管理者入口（`/admin`）には、利用者のパスワードでは入れません。
- 圃場が 0 枚でもログインや指示の受け取り・日誌はできます。塗り・ガント・指示の作成は、圃場が 1 枚以上あるときだけです。

### パソコンとスマホ

画面の幅が狭い（おおよそスマホ）と、次は使えません。案内が出ます。

| 画面 | スマホ |
|---|---|
| 圃場台帳・地図・作業場所・下地 | 不可（パソコンで） |
| ガント | 不可（パソコンで） |
| 日次一覧 | 不可（パソコンで） |
| 指示を出す・直す・閉じる | 不可（パソコンで） |
| 他人の対象圃場のまとめ | 不可（パソコンで） |
| 指示一覧・指示の進捗閲覧・日誌 | 可 |
| ログイン・招待・パスワード・言語 | 可 |

---

## 2. ログイン・パスワード・ログアウト

1. `/` を開き、メールアドレスとパスワードを入れて「入る」。
2. 忘れたとき: 「パスワードを忘れた」→ メールを入れて「案内を送る」→ 届いた案内から新しいパスワードを「決める」（8 文字以上）。
3. ログイン後に変える: ナビの「パスワード」→ 今の／新しい／確認 →「変える」。
4. 「ログアウト」で出ます。

利用者と管理者は入口が別です。案内メールを送る入口を間違えないでください。

---

## 3. ホームとナビ

ナビ: 言語｜ホーム｜圃場台帳｜地図｜作業｜日次一覧｜招待｜パスワード｜ログアウト

ホームには、次への出口もあります。

- 圃場が 1 枚以上あるとき: 「日次一覧」「作業」「ガント」「指示を出す」
- 常時: 「指示」「他人の対象圃場」

---

## 4. 利用者を招待する

1. 「招待」を開く。
2. 相手のメールアドレスを入れて「招待する」。
3. 画面に出る「初期パスワード」を相手に伝えます（この画面を離れると同じ文字列は再び出せません）。
4. 相手は利用者入口から、そのメールと初期パスワードで入ります。

すでに利用者として招待済みのメールや、管理者のメールは招待できません。招待の取消しは管理者の仕事です。

---

## 5. 作業場所と下地（パソコン）

地図を初めて使うときは、先に作業場所の範囲を決めます。

1. 「地図」→ 作業場所の画面へ進む（未設定なら自動で案内されます）。
2. 地理院地図を動かして範囲を決める。
3. 「空中写真で最終確認」で見たあと、「この範囲を作業場所にする」。直すなら「地理院地図に戻って範囲を直す」。
4. 保存中は「作業場所を保存し、下地を取り込んでいます…」と出ます。完了まで待ちます。

あとから変えるときは地図の「作業場所を変える」から同じ流れです。

### 下地

地図の操作で「下地」を選びます。

- 「この範囲の下地を自動で取り込む」
- 手でファイルを入れる種類: 空中写真／標準地図／衛星
- 位置の微調整（西東南北・縮小拡大など）のあと「下地の位置を保存」
- 「下地の種類」で、取り込んだ下地を切り替え

初期の表示は、作業場所の空中写真を想定しています。

---

## 6. 圃場台帳（パソコン）

「圃場台帳」で、自分の圃場の一覧を見ます。

- 名前・ha・㎡・メモを直して「保存」（いつでも直せます）
- 形から出した面積が初期値です。台帳で直した ha／㎡は台帳の表示用です（塗りの％の分母はこれまでどおり形の面積です）
- 「削除」で消す（ガントの対象や指示の対象からは外れます。ガント行や指示そのものは残ります）
- 「地図へ」で地図画面へ

名前の重複は許されます。形の編集は地図側です。

---

## 7. 地図で圃場の形を作る・直す（パソコン）

地図の「操作」から選びます。

| 操作 | やること |
|---|---|
| 手描き | 閉じた多角形を描き、名前を付けて「圃場を保存」 |
| 修正 | 頂点を動かして「形と名前を保存」 |
| 分割 | 圃場を選んで切り線を引き「分割を保存」（塗りが残っているとできないことがあります） |
| 合筆 | 残す圃場と他の圃場を選んで「合筆する」（塗りが残っているとできないことがあります） |
| 区画取込 | GeoJSON などを取り込む |

「やめる」で操作をやめます。

---

## 8. 作業名と塗り（パソコン）

実績の正本は地図の塗りです。画面は上から順に分かれています。

1. 作業名を入れ、「この作業名で見る」（メニューからでも、塗りからでも可）。
2. **塗る**: 「ブラシ」でなぞる →「塗りを確定する」。やめるなら「下書きを捨てる」。確定と破棄は下書きがあるときだけ押せます。
3. **選んだ圃場**: 地図で圃場をクリックしてから「全面完了」や「この作業名の塗りを全部消す」。
4. **選んだ塗り**: 地図で塗りをクリックしてから「この塗りを消す」。
5. **ほか**: 「圃場を直す」「下地」へ。

色の目安: 未／一部／済。

- 「田植え」と「田植」は別の作業名です（完全一致）。
- 他人の圃場は見えても塗れません。自分の圃場だけです。
- ガントや指示が無くても、塗りだけで実績になります。

---

## 9. 作業（パソコン・圃場が 1 枚以上）

題名やガント画面とは別に、作業そのものを管理します。

1. 「作業」を開く（ナビまたはホーム）。
2. 一覧で全作業を見る（関連する題名も表示）。
3. 「新しい作業を追加」で作業タイトル・開始・終了を入れて追加。関連する題名は任意（「なし」でも可）。開始・終了の初期値は今日 08:00〜17:00。
4. 作業を選んで、関連する題名・作業タイトル・時刻・実行状態・作業名・対象圃場を直し「保存」。対象圃場はチェックで追加・外し。
5. 同じ編集欄で **作業時間**（開始・終了。複数可。親の予定の外や重なりも可）と **チェック項目**（項目名・まだ／やった）を足す・直す・消す（確認あり）。新規の追加欄には出しません。
6. 「削除」で一覧から消す（確認あり）。付いていた作業時間・チェックも通常の一覧からは見えなくなります。

注意:

- **作業タイトル**は一覧やガントの棒に出る名前です。題名（グループ）や塗り用の**作業名**とは別です。
- 対象圃場がある作業は、作業名が必須です。
- 作業時間やチェックを変えても、実行状態・塗り・面積％は自動では変わりません。
- ガントの棒グラフ表示は「ガント」画面で、題名を選んで行います。題名のない作業はガントの題名配下には出ません。

---

## 10. 日次一覧（パソコン・圃場が 1 枚以上）

今日／直近7日／すべての予定を、実行状態で回す画面です。

1. 「日次一覧」を開く（ナビまたはホーム）。開いた直後は直近7日・未着手＋着手中。
2. 期間と状態フィルタを変え「適用」。
3. 各行で実行状態を選んで保存。作業時間の件数とチェック進捗（やった数／総数）の要約が見えます。詳しい編集は「作業を開く」から。

注意:

- スマホ幅では使えません（パソコン案内のみ）。
- 作業時間が無い行は「作業時間なし」、チェックが無い行は「チェックなし」と出ます。

---

## 11. ガント（パソコン・圃場が 1 枚以上）

自分用の予定を題名ごとに時間軸で見る画面です。進捗％と地図もここで確認します。指示とはつながりません。作業の追加・編集は「作業」画面でもできます。

1. 「ガント」を開く。見出し下の案内どおり、まず題名を選ぶ（または足す）。
2. 「題名」を一覧から選ぶ。まだ無ければ「題名を足す」で追加する。選んだ題名は名前の変更・削除ができる（削除すると中の作業も一覧から消える）。
3. 「時間の範囲」: 日／週／8週／月／3ヶ月／6ヶ月（開いた直後の「日」は、今日 0:00 からおおよそ 3 日分）。長い作業は「3ヶ月」「6ヶ月」で軸を広げられる。
4. 「向き」: 「時刻を横」（初期）または「時刻を縦」（タスクが横に並ぶ）。
5. 「この題名に作業を足す」で作業タイトル・開始・終了を入れて追加（開始・終了は分までの日時。初期は今日 08:00〜17:00）。
6. 作業を選んで、関連する題名・作業タイトル・時刻・実行状態・作業名・対象圃場を直し「保存」。
7. 同じ行編集で作業時間・チェック項目も足す・直す・消せます（作業画面と同じ。棒からは変えられません）。

注意:

- 「削除」で一覧から消す（確認あり）。作業と日次％の履歴は残ります。
- 「振り返り」で、その作業の日付ごとの確定％を見られます（適用外の日は「—」）。
- ログインやガントを開いたとき、東京時間の前日までの未確定分が自動で確定されます。
- 対象圃場がある作業は、作業名が必須です。
- 対象も作業名も無い作業、作業名だけの作業はメモで、パーセントは出ません。
- 対象と作業名がある作業を選ぶと、パーセントサークルと地図色が出ます（分母は対象面積、分子はその作業名の塗り）。
- 対象に付けられるのは自分の圃場だけです。

---

## 12. 指示を出す・直す・閉じる（パソコン・圃場が 1 枚以上）

1. 「指示を出す」（またはホームのリンク）。
2. 日付、開始・終了（同じ日）、作業名、依頼文、受け手のメール、対象圃場（自分の圃場）を入れて「指示を保存」。
3. 自分自身は受け手に含められません。
4. 「指示」一覧の「出した指示」から詳細を開く。
5. 進行中のうち、依頼文と時刻だけ直せます。受け手と対象圃場は変えられません。
6. 終わったら「この指示を閉じる」。閉じた指示は再開しません。日誌が無くても閉じられます。

---

## 13. 指示を見る・日誌を書く（スマホでも可）

1. 「指示」で「受けた指示」「出した指示」を見る。
2. 一件を開くと、依頼内容と対象圃場の進捗（色）が見えます。
3. 受け手で、まだ閉じておらず日誌を書いていないとき: 「日誌を書く」。
4. 日誌は指示 1 件につき受け手 1 人 1 通です。書いたら直せません。閉じたあとは書けません。

スマホでは、指示の作成・修正・閉じはできません（パソコンで）。閲覧と日誌はできます。

---

## 14. 他人の対象圃場（パソコン）

一度でも指示の対象になった相手の圃場だけが見えます（載っていなかった枚は見えません）。

1. 「他人の対象圃場」を開く。
2. 作業名を選んで「この作業名で見る」。
3. 地図の色と、所有者メール付きの一覧で進捗を確認します。

ここから塗ることはできません。相手との見え方を消す「関係を切る」は管理者だけが行います。

---

## 15. よくある制限

| 状況 | 結果 |
|---|---|
| 圃場が 0 枚 | 塗り・ガント・指示作成は不可。指示の受け取りと日誌は可 |
| スマホ幅 | 台帳・地図・ガント編集・指示作成／閉じ・他人のまとめは不可 |
| 言語切替 | 画面文言だけ。入力した圃場名・作業名・日誌などはそのまま |
| 関係の切断 | 利用者画面には無い（管理者へ依頼） |
| ガントと指示 | 自動ではつながらない。別々の予定 |

---

## 16. 典型的な流れ（一人で使う）

1. 招待されてログインする（必要ならパスワードを変える）。
2. 作業場所を決め、下地を取り込む。
3. 地図で圃場を手描き（または取込）し、台帳で名前を整える。
4. 作業名を付けて地図を塗り、進捗色を見る。
5. 必要ならガントに予定を置き、対象付き行で％を見る。
6. 他人に頼むときは指示を出し、相手の日誌と塗りを待つ。自分で閉じる。
