# ISAS 要求仕様書（第1版）

- 版: 0.8
- 状態: 合意
- 日付: 2026-09-12
- 本書は「何を作るか（What）」の正本である。構成技術（How）は別とする。工程ごとの振る舞いは [基本仕様書.md](基本仕様書.md) とする。第1版の論理構成は [基本設計書.md](基本設計書.md) とする。

イチセ・スマート・アグリ・システム（ISAS）は、招待制の営農支援Webアプリケーションである。第1版は KSAS の基本（圃場台帳・指示・日誌・進捗）に、時刻つきガントを足す。参考は KSAS の作業進捗（地図の色と円グラフ／％）であり、ガントは KSAS に無い追加要求である。

---

## 1. 目的

- 農地図を編集し、作業結果が圃場のどこまで終わったかを一目で分かるようにする。
- 作業進捗を、農地図の色とパーセントサークルで見る。
- 予定をガントチャートで時刻まで管理する。
- 時々、他の営農者や助っ人に作業を依頼し、結果を地図に戻す。

## 2. 第1版に含めないもの

次は第1版の対象外とする。

- 農機連携、食味・収量、可変施肥、ドローン
- GAP、農薬基準チェック、在庫
- 作付計画マスタ
- オフライン同期
- 写真、通知、印刷、Excel 出力
- 公開SaaS、誰でも登録、営農者ごとの別システム連携
- 画面以外の全文翻訳、RTL、全世界言語基盤

## 3. 用語

| 用語 | 意味 |
|---|---|
| 営農者 | このISASに招待された利用者。自分の圃場を持ってよい。圃場ゼロでもよい。 |
| 圃場 | 営農者が台帳に持つ区画。名前と形を持つ。面積は形から求める。 |
| 作業名 | 実績を束ねる名前。塗り・ガント・指示が同じ実績を指すための一致キー。 |
| 塗り | ある圃場の、ある作業名に対する完了範囲。確定したポリゴン。面積の正本。 |
| ガント | 自分用の工程メモ。行は自由。時間軸は日時（時刻まで）。向きは横／縦を切替えられる。 |
| 指示 | 他人への依頼票。ガントとは紐づけない。 |
| 日誌 | 指示に対する「やった」記録。任意。圃場内訳は持たない。 |

## 4. 利用者と運用

- イチセが1つのISASを置き、知っているアカウントを招待する。公開登録はしない。
- ログインは、招待したアカウント（メール等）とパスワードで足りる。
- 各自が自分の圃場を持てる。圃場ゼロの利用者も、指示を受けて日誌を書ける。
- 普段は一人で使う。時々、他の営農者や助っ人に作業を頼む。
- パソコンが主。スマホは進捗の閲覧と日誌だけとする。地図の塗り・境界編集・ガント編集はパソコンとする。
- 第1版はオンライン必須とする。圏外では使わない。
- 規模の目安は、一人あたりおおよそ150枚とする。
- 画面のボタン・見出し・日付表示は日本語／英語を切り替えられる。最初に出す言語は日本語とする。ログイン後に選んだ言語はアカウントに残し、別の端末でも同じにする。管理者入口・利用者入口はログイン前から切替えられる。管理者の画面も切替の対象とする。圃場名、作業名、日誌、依頼文は入力したままとし、翻訳しない。作業名も翻訳しない。

## 5. 予定

予定は二冊とする。同期しない。

### 5.1 ガント（自分用）

- 行は自由なタスクでよい。ソフト削除できる（一覧から消すが履歴は残す）。日次の確定％で振り返れる。
- 時間軸は日時とし、開始・終了は時刻まで持てる。画面は行がタスク、時間軸が日時の工程ガントとする。開いたときは今日を含む数日を見せ、時刻が読めるようにする。時間軸は横／縦を切替えられる（縦のときはタスクを横に並べる）。週・8週・月・3ヶ月・6ヶ月へ広げられる。
- 対象圃場は任意。付けられるのは自分の圃場だけとする。他人の圃場はガントの対象にできない。
- 対象圃場がある行は、作業名を必須とする。
- 圃場も作業名も無い行、および作業名だけあり対象圃場が無い行はメモとし、パーセントサークルは出さない。
- ガントの題名と作業名は別欄でよい。
- ガントを使えるのは、圃場を1枚以上持つ利用者とする。

### 5.2 指示（他人への依頼）

- 持つもの: 日付、開始・終了時刻、作業名、依頼文、受け手（複数可）、対象圃場（複数可）。
- 対象圃場は、指示を出した人の圃場だけとする。受け手の圃場や混在は不可とする。
- 出した人が手で閉じる。閉じた指示は再開しない。閉じる前は依頼文と時刻だけ直せる。
- 自分の作業に指示は不要とする。出した人自身は受け手に含めない。ガントも任意とする。実績は地図の塗りで足りる。
- 進行中の指示がある相手とは、関係を切れない。関係を切れるのは管理者だけとする。切る単位は二人のあいだ（双方向）とする。どちらの向きでも進行中の指示があれば切れない。

## 6. 作業名

- ガント行・指示・塗りは、いずれも作業名欄を持つ。
- 一致は文字列の完全一致とする。前後の空白だけ無視する。「田植え」と「田植」は別の実績とする。
- 表記ゆれや日英の同義語は第1版で吸収しない。
- 入力候補は、自分が出した／塗った作業名だけとする。他人の作業名は候補に出さない。
- 題名や依頼文は作業名と別欄とし、長く書いてよい。

## 7. 圃場と地図

### 7.1 台帳

- 必須は名前と形だけとする。面積は形から自動で求める。
- 作物、作期、地番、所有者は第1版の必須としない。
- 一覧の面積は ha、詳細は ㎡ で表示する。

### 7.2 形の入力

- 手描きで境界を描ける／直せる。1枚の分割と、複数枚の合筆ができる。
- 初期形は、eMAFF 農地ナビ／筆ポリゴン等から取得した GeoJSON などを**手作業で**取り込める。下地は、作業場所の範囲について自動取得できる。失敗時は手作業のファイル取込を残す。
- 下地は、作業場所の範囲について自動取得した画像（標準地図／空中写真／衛星）を切り替えられる。取得元の第一候補は eMAFF、取れないときは国土地理院の公開タイルから**候補範囲どおり**に座標付きで生成する（空中と衛星は別縮尺）。手作業の画像取込も残す。
- 地図の初期表示は、その利用者に紐づく作業場所の空中写真とする。作業場所は利用者に固定で紐づき、圃場の広がりでは変えない。
- **作業場所の決定**は、パソコンの地図で国土地理院タイルを見ながら位置と範囲を決める。最終確認として空中写真（eMAFF 優先、不可時は地理院）を**候補範囲のまま**一時表示してから確定する。確認中は地理院地図に戻って範囲を直せる。変更するときはいまの範囲で開き直す。地名検索は必須にしない。
- 農地ナビの画面埋め込みと画面キャプチャ専用 UI はしない。サーバが範囲限定で取得して保存・表示する。
- 塗る対象は、取り込んで直した自分のポリゴンとする。

### 7.3 塗り（面積の正本）

- 完了面積の正本は地図の塗りとする。
- 塗りは **圃場 × 作業名** に紐づく。
- 入力はブラシでよい。確定するとポリゴンになり、その面積を使う。
- 1枚の圃場の中を分割して、済／未を付けられる。
- いずれかの作業名の塗りが残っている圃場は、台帳上の分割・合筆はできない。塗りを消してから行う。
- 同じ圃場・同じ作業名の塗りが複数あれば、面積は合わせる。
- ある作業名について、圃場を全面完了にする操作（全塗り相当）を用意する。
- 助っ人は塗れない。塗りは、その圃場の所有者がパソコンで行う。

## 8. 進捗

### 8.1 パーセントサークル

- 分母・分子は面積とする。枚数ではない。
- 対象は、**今見ているガント行**に限る。
- 分母: その行の対象圃場の合計面積。
- 分子: それらの圃場について、その行の作業名の塗り面積の合計。
- ガント行を選んでいないときは、パーセントサークルを出さない。

### 8.2 地図の色

- 自分の全圃場を出す。
- ガント行を選んでいるとき: その行の対象圃場は、その作業名の済／一部／未で色を付ける。それ以外の自分の圃場は薄い色とする。
- ガント行を選んでいないとき: 作業名を地図側で選ぶと、自分の全圃場にその作業名の塗り色を出す。選ばなければ形だけとする。

### 8.3 日誌と％

- 日誌は指示1件に対する報告とする。受け手の人数ぶん、各人が任意で1通書いてよい。
- 日誌は「やった」事実だけとする。どの圃場をどれだけやったかの内訳は持たない。圃場別の内訳は地図の塗りだけが持つ。
- 日誌に完了割合の％を書いても、それは記録に残すだけとする。サークルも地図色も日誌％で上書きしない。
- 日誌は任意とする。1通も無くても、出した人が地図を塗って指示を閉じられる。書いた日誌は直せない。閉じたあとは書けない。

## 9. 他人の圃場の見え方

- ログインした直後の地図の主は、自分の圃場とする。
- 一度でも指示の対象になった相手の圃場だけ、以降も見える。対象外の枚は見えない。
- その見える相手の圃場に限り、関係した指示の作業名の進捗色（所有者の塗り）を出す。
- 関係を切ると、互いに相手の圃場は見えなくなる。切れるのは管理者だけとする。切る単位は二人のあいだ（双方向）とする。どちらの向きでも進行中の指示があるときは管理者も切れない。
- 相手の全圃場や、依頼したことが無い営農者の圃場は見えない。

## 10. 画面の役割（第1版）

| 場所 | できること |
|---|---|
| パソコン・地図 | 境界の描画・修正、取込、下地切替、塗り、全面完了、作業名による色表示 |
| パソコン・ガント | 行の作成・時刻編集、自分の圃場の対象化、作業名、進捗％（対象付き行） |
| パソコン・指示 | 依頼の作成・閉じる、受け手と圃場の指定 |
| パソコン・台帳 | 圃場の名前、形の一覧 |
| スマホ | 関係した進捗の閲覧（対象圃場が見える位置。作業場所の値は変えない）、指示に対する日誌 |

## 11. 確定した前提

1. 第1版の成功条件は、招待したメンバが、自分の農地図とガントと依頼で作業の予定と結果を見られることである。
2. 実績の正本は地図である。予定の正本は二冊（ガントと指示）であり、混ぜない。
3. 作業名は一致キーであり、翻訳も表記ゆれ吸収もしない。
4. eMAFF は形と下地画像の入手元である。作業場所のナビには国土地理院タイルを使う。塗りの正本はISAS側のポリゴンである。
