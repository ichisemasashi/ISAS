# ISAS 要求仕様書（第2版）

- 版: 0.2
- 状態: 草案
- 日付: 2026-09-21
- 第1版の正本は [要求仕様書.md](要求仕様書.md) とする。本書は第2版で「何を足すか（What）」の草案である。構成技術（How）、工程分割、基本設計は、合意のあと別文書とする。
- 第1版の前提（実績の正本は地図の塗り、予定はガントと指示の二冊、招待制、パソコン主）は、本書で明示的に変えない限り引き継ぐ。

イチセ・スマート・アグリ・システム（ISAS）の第1版は、圃場台帳・塗り・ガント（題名・表示名・作業名）・指示・日誌・面積％までを揃えた。一方、日々の農作業を「今日やること」として回す実行管理まではカバーしていない。第2版は、その不足の解消を目標の一部とする。

---

## 1. 第2版の狙い

### 1.1 日々の農作業タスク

第1版の「タスク」は、営農の予定メモ（ガント）・面積進捗（塗りと％）・他者依頼（指示）である。第2版では、現場の日次オペレーションに必要な実行管理を足す。

成功の目安は、招待した利用者が、**今日／今週にやる作業を一覧し、予定と実績のつながりを追い、面積では測れない作業も含めて現場で回せる**こととする。

### 1.2 X 型メモ

第2版の目標の一部として、**X（旧 Twitter）に似た短いメモを時系列で残す機能**を検討する。公開 SNS の再現ではなく、招待された利用者の営農メモとする。機能の採否は §7 のマッピング案を正とする（合意で更新する）。

---

## 2. 第1版の位置づけ（不足の前提）

次は第1版どおりであり、第2版で解消する対象の背景とする。

| 系統 | 第1版での役割 |
|---|---|
| 題名・表示名・作業名 | ガント上のグループ／行ラベル／塗り・指示と突合するキー |
| `/works`・`/gantt` | 作業の CRUD と時間軸・面積％ |
| 地図の塗り | 実績の正本（圃場 × 作業名の完了範囲） |
| 指示・日誌 | 他人への依頼と受け手の報告 |

ギャップは「題名・作業名が足りない」ことではなく、**日々の実行管理に必要な周辺が第1版の対象外であること**にある。

---

## 3. 第2版で解消する不足（目標の一部）

以下は優先度の高い順とする。各項は第2版の要求候補であり、工程への割当・必須／任意の切り分けは合意後に定める。

### 3.1 「今日やること」の実行管理

- 今日／今週の作業一覧、完了チェック、未着手フィルタがない。
- ガントは時間バーと面積％が中心で、ToDo 型の「やる／やった」状態がない。
- カレンダー専用 UI は第1版で対象外である。

**第2版で求めること（草案）:** 日次の実行一覧（今日／今週）、完了・未着手などの状態、必要なフィルタを持てるようにする。

### 3.2 予定と実績の接続が弱い

- ガント行を閉じなくても塗りで実績になる。逆に、ガントだけでは実績にならない。
- ガントと指示は紐づけ・同期しない（別冊）。
- 「予定した作業が今日どこまで終わったか」を一つの流れで追いにくい。

**第2版で求めること（草案）:** 予定（ガント／指示）と実績（塗り等）のつながりを、利用者が追えるようにする。自動の完全同期を必須とはしないが、手動リンクや「この予定に対する実績」の見え方を検討する。

### 3.3 進捗の単位が面積％に偏る

- 「何時間やったか」「誰がやったか」「何回目か」の作業ログがない。
- 面積で測れない作業（点検、書類、資材手配、移動など）を扱いにくい。
- 日誌は指示向け・訂正不可・圃場内訳なしである。

**第2版で求めること（草案）:** 面積以外の実績（時間・担当・チェック項目など）を、必要な範囲で持てるようにする。

### 3.4 現場での入力・伝達が弱い

- 助っ人は塗れない（所有者の帰宅後塗りが前提）。
- スマホは進捗閲覧と日誌のみ（塗り・ガント編集・指示作成は不可）。
- 通知・オフライン・写真は第1版の対象外である。その場の依頼・圏外記録・証拠はシステムの外になる。

**第2版で求めること（草案）:** 現場での簡易な実績入力・伝達の手段を足す。通知・オフライン・写真の採否は、本節の他項とあわせて第2版の範囲合意で決める。

### 3.5 担当・繰り返し・リマインドがない

- 自分用ガントに担当者アサインがない（指示の受け手以外）。
- 「毎週防除」「隔日かん水」などの繰り返しルールがない。
- 期限超過・未着手の通知がない。

**第2版で求めること（草案）:** 担当の割当、繰り返し予定、未着手・期限の気づき（リマインド）を、必要な範囲で持てるようにする。

### 3.6 作業の属性・周辺資源とつながらない

- 作業名マスタ／改名がなく、表記ゆれで％が分断されうる。
- 作物・作付・農薬・在庫・機械は第1版の対象外である。
- 資材・機械・天候条件をタスクに紐づけられない。

**第2版で求めること（草案）:** 作業名の整理（マスタや改名など）と、タスクに必要な周辺属性の接続を検討する。在庫・農薬基準・農機連携の全面導入は、第1版 §2 と同様に第2版でも必須としない（範囲合意で切り出す）。

### 3.7 横断的な見通しが弱い

- 複数ガント行の合算％がない。
- 題名なし作業はガント棒に出ない（`/works` と `/gantt` の切れ目）。
- 「全圃場・全作業の今日の進捗」ダッシュボードがない。

**第2版で求めること（草案）:** 今日の進捗や複数予定の横断的な見通しを持てるようにする。

---

## 4. 第2版の分岐（合意で選ぶ）

日々の農作業タスク管理を載せるとき、次のどれを軸にするかが分岐点である。第2版の詳細要求は、この選択のあとで書く。

1. **日次実行層**（今日のリスト／完了／フィルタ）をガントの上に足す。
2. **予定と塗り・指示をつなぐ**（手動リンクや「予定に対する実績」）。
3. **面積以外の実績**（時間・担当・チェック項目）を認める。

三つを同時に全部やる必要はない。§3 の優先に沿い、最小セットから合意する。

---

## 5. 第2版でも引き継ぐ原則（草案）

次は、§3 を足しても崩さないことを原則とする。変えるときは明示する。

1. 実績の正本の考え方を曖昧にしない（塗りを捨てて日誌だけにしない）。
2. 予定の二冊（自分用と依頼）を、利用者が区別できること。
3. 招待制・一人あたり規模の目安など、第1版の運用前提は維持する。
4. 第1版 §2 の対象外のうち、農機連携・GAP・公開SaaS 等は、本書 §3 に無い限り第2版の必須にしない。

## 6. 本書の扱い

- 本書は草案である。合意前に基本仕様・基本設計・工程表へ展開しない。
- 合意したら、版と状態を更新し、第1版の要求仕様書からの参照を正にする。
- §3 の各項は、合意時に「必須／任意／対象外」へ振り分ける。
- §7 の「ISAS対応」も合意で更新する。取り込む項目だけが第2版メモの必須候補になる。

## 7. X 機能と ISAS 対応（マッピング案）

参考は既存の X（旧 Twitter）の機能面である。ISAS は招待制の営農支援であり、**公開 SNS・広告・収益・フォロー網の再現はしない**。

### 7.1 判定の意味

| ISAS対応 | 意味 |
|---|---|
| 取り込む | 第2版メモ（またはその隣接）の要求候補とする |
| 捨てる | 第2版では作らない。SNS 固有／ISAS の運用に合わない |
| 後回し | 有用だが第2版の初回必須にはしない。合意で繰り上げ可 |

### 7.2 判定の方針（草案）

1. **自分用〜招待メンバ内の短い時系列メモ**を核とする（ポスト・スレッド・タグ・検索・ファイル添付・編集しない削除・下書き）。
2. **拡散・おすすめ・トレンド・収益・広告・AI・音声ライブ**は捨てる。公開後の投稿編集も捨てる。
3. **通知・スマホ投稿・他者への見える範囲・位置情報・メンション等**は、§3（現場入力・リマインド）や共有設計と衝突しうるため後回しとし、範囲合意で決める。ファイル添付（一般ファイル）は取り込む。
4. 既存の **指示・日誌・ガント** と役割が重なるものは、新規に作らず既存を使うか、後回しで整理する。

### 7.3 投稿（ポスト）本体

| 機能 | 内容 | ISAS対応 |
|---|---|---|
| テキスト投稿 | 短文中心のメモ投稿 | 取り込む |
| スレッド | 複数メモを連ねた一連の記録 | 取り込む |
| メディア（画像・GIF・動画） | 投稿への添付 | 取り込む（「画像・GIF・動画」と条件を絞らずに一般的なファイルが対象） |
| リンク | URL の添付 | 取り込む（参考 URL・資材ページ等） |
| 投票（ポール） | 選択肢付きアンケート | 捨てる（意思決定は指示・口頭で足りる） |
| 位置情報 | 投稿への場所付与 | 後回し（圃場紐づけで代替できるなら不要） |
| 下書き | 未公開の下書き | 取り込む |
| 予約投稿 | 日時指定の公開 | 後回し（ガント／繰り返し予定と役割が重なる） |
| 投稿の編集 | 公開後の修正 | 捨てる |
| 削除・非表示 | 自分のメモの削除等 | 取り込む（ソフト削除を基本とする案） |
| 長文記事（Articles） | ブログ寄りの長文 | 捨てる（短文メモが核。長文は別手段） |

### 7.4 反応・拡散

| 機能 | 内容 | ISAS対応 |
|---|---|---|
| いいね | 反応の表明 | 後回し（ピン留め・重要マークで足りるなら簡易化） |
| リポスト | 他者投稿の拡散 | 捨てる（公開拡散は不要） |
| 引用（Quote） | コメント付き再投稿 | 捨てる（スレッド／返信で足りる） |
| 返信（リプライ） | 投稿への返信・会話 | 取り込む（メモへのコメント。範囲は招待メンバ内） |
| メンション | `@ユーザー` で指名 | 後回し（指示の受け手・担当と整理してから） |
| ハッシュタグ | `#話題` で紐づけ | 取り込む（作業名・圃場・季節タグ等。表記は合意で） |
| ブックマーク | 後で読む個人保存 | 取り込む（自分用の「残す」） |

### 7.5 タイムライン・発見

| 機能 | 内容 | ISAS対応 |
|---|---|---|
| For You（おすすめ） | アルゴリズム推薦 | 捨てる |
| Following（フォロー中） | フォロー先中心の TL | 捨てる（フォロー網は作らない） |
| トレンド | 話題のキーワード | 捨てる |
| 検索 | キーワード・投稿検索 | 取り込む |
| 高度な検索 | 期間・除外語などの絞り込み | 取り込む |
| リスト | アカウント群の専用 TL | 捨てる（アカウント横断の SNS 用。タグ／フィルタで代替） |
| コミュニティ | テーマ別グループ投稿 | 後回し（題名・作業グループと役割整理後） |
| 探索／話題タブ | ニュース発見 | 捨てる |

**ISAS でのタイムライン案:** 「自分のメモの時系列」を主とする。共有する場合は招待メンバ内の明示共有に限り、おすすめ・トレンドは置かない。

### 7.6 関係・プロフィール

| 機能 | 内容 | ISAS対応 |
|---|---|---|
| フォロー／解除 | 他アカウント購読 | 捨てる |
| ブロック | 接触遮断 | 捨てる（管理者の関係切断で足りる） |
| ミュート | 表示抑止 | 捨てる |
| 鍵アカウント | 承認制の非公開 | 捨てる（ISAS 全体が招待制。メモは既定で非公開〜メンバ内） |
| プロフィール演出 | ヘッダー・自己紹介・スポットライト | 捨てる（既存アカウント情報で足りる） |
| 認証バッジ | チェックマーク等 | 捨てる |
| 個人／プロ用アカウント切替 | ビジネス表示 | 捨てる |
| 組織の関連アカウント | 配下アカウント表示 | 捨てる |

### 7.7 メッセージ・ライブ

| 機能 | 内容 | ISAS対応 |
|---|---|---|
| DM | 1対1／グループ私信 | 捨てる（依頼は指示、メモコメントは返信で足りる） |
| Spaces | ライブ音声 | 捨てる |
| ライブ／動画視聴フィード | 配信・視聴まわり | 捨てる |

### 7.8 通知・設定・安全

| 機能 | 内容 | ISAS対応 |
|---|---|---|
| アプリ内通知 | 反応・言及の通知 | 後回し（§3.5 のリマインドと一体で決める） |
| プッシュ／メール通知 | 端末・メール通知 | 後回し（第1版は通知対象外） |
| 表示設定 | テーマ等 | 後回し（日英切替は第1版済み。見た目の拡張は必須でない） |
| センシティブ表示制御 | 閲覧警告 | 捨てる（公開 SNS 向け） |
| 報告（通報） | 不適切投稿の通報 | 捨てる（招待制・少人数。管理者運用で足りる） |
| 二要素認証等 | アカウント保護 | 後回し（認証強化はメモ機能と独立） |
| 返信できる相手の制限 | 公開範囲の細分 | 後回し（共有範囲の設計と一体） |

|---|---|---|
| アナリティクス | インプレッション等 | 捨てる |

| 収益化・購読 | クリエイター収益 | 捨てる |
| 広告出稿 | プロモーション | 捨てる |

### 7.10 AI・決済・有料階層

| 機能 | 内容 | ISAS対応 |
|---|---|---|
| Grok 等の内蔵 AI | 生成・質問応答 | 捨てる（第2版の必須にしない） |
| 決済／送金 | everything app 寄りの決済 | 捨てる |
| Premium 階層 | 機能差のある有料プラン | 捨てる（ISAS は招待制の単一運用） |

### 7.11 取り込む項目の要約（第2版メモの核）

次を第2版メモの最小核とする案である（§7.3〜§7.10 の「取り込む」に合わせる）。

1. 短いテキストの時系列投稿（下書き・削除。公開後の編集はしない）
2. スレッド（連ねる）
3. 返信（メンバ内コメント）
4. タグ（ハッシュタグ相当）と検索（高度な検索＝期間・除外語などの絞り込みを含む）
5. ブックマーク（自分用に残す）
6. リンク添付
7. ファイル添付（画像・GIF・動画に限らず、一般的なファイルを対象とする）
8. 既定は非公開〜招待メンバ内（公開 SNS にしない）

### 7.12 後回しの要約

- いいね相当（またはピン／重要）
- メンション、予約投稿、位置情報、コミュニティ
- 通知（アプリ内・プッシュ／メール）
- 共有範囲の細分（返信できる相手の制限など）
- 表示設定の拡張、二要素認証など認証強化（メモと独立）

### 7.13 捨てる側の要約

- 公開後の投稿編集
- フォロー網・おすすめ・トレンド・リスト・探索
- リポスト／引用による拡散
- DM・Spaces・ライブ
- プロフィール演出・認証バッジ・鍵アカの SNS 的公開制御
- 広告・収益・分析・Media Studio・X Pro
- AI・決済・有料階層・投票・長文 Articles

### 7.14 既存 ISAS 機能との役割分担（草案）

| 欲しいこと | 使うもの |
|---|---|
| いつ何をする予定か | ガント／作業（第1版）＋§3 の日次実行 |
| 他人への依頼 | 指示（第1版） |
| 依頼への「やった」 | 日誌（第1版） |
| 面積の完了 | 塗り（第1版） |
| 短く残す現場メモ・気づき・日誌にならない記録 | **第2版メモ（本節）** |
| メモに残す参考資料・現場の添付 | **第2版メモのファイル添付（本節）**（塗りや％の正本にはしない） |

メモは塗り・％・指示を置き換えない。公開後は編集せず、直すときは削除（ソフト削除）と作り直しを基本とする。§5 の原則（実績の正本を曖昧にしない）を守る。
