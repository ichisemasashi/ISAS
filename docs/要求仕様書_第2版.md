# ISAS 要求仕様書（第2版）

- 版: 1.4
- 状態: 合意
- 日付: 2026-09-25（1.4: レビュー記録票 RV-V2-001 の R-01〜R-03 を受け、日次一覧の期間・遅れ・状態保存を改訂）
- 第1版の正本は [要求仕様書.md](要求仕様書.md) とする。本書は第2版で「何を足すか（What）」の正本である。構成技術（How）は別とする。工程ごとの振る舞いは、合意後に基本仕様書へ足す。第2版の論理構成は、合意後に基本設計書へ足す。工程の順と完了条件の草案は [工程表_第2版.md](工程表_第2版.md) とする。
- 第1版の前提（実績の正本は地図の塗り、予定はガントと指示の二冊、招待制、パソコン主）は、本書で明示的に変えない限り引き継ぐ。
- 第2版で足すのは、**日々の農作業のタスク管理**と **X 型メモ**の二つだけとする。

イチセ・スマート・アグリ・システム（ISAS）の第1版は、圃場台帳・塗り・ガント（題名・表示名・作業名）・指示・日誌・面積％までを揃えた。第2版は、ガント作業に日次の実行状態を足し、招待メンバ内の短い時系列メモを足す。

---

## 1. 目的

- 今日／今週にやるガント作業と、終わっていない遅れた作業を一覧し、未着手／着手中／完了で回せるようにする。
- 面積％では測れない作業も、同じ実行状態（および必要な時間・チェック）で扱えるようにする。
- 招待メンバが読める短いメモを時系列で残し、現場の気づきや参考資料を共有できるようにする。

## 2. 第2版に含めないもの

次は第2版の対象外とする。第1版 §2 の対象外も、本書で明示しない限り対象外のままとする。

- 予定（ガント／指示）と実績（塗り）の自動同期、および必須の手動リンク
- ガント作業への担当者アサイン
- 繰り返し予定（毎週防除など）
- 期限・未着手などの通知（アプリ内・プッシュ・メール）
- スマホからのタスク完了チェック、およびガント作業の実行状態の変更
- 公開 SNS 的な機能（フォロー網、おすすめ、トレンド、リポスト、引用、DM、Spaces、収益、広告、認証バッジ等）
- メモの編集窓が閉じたあとの公開後編集（窓のあいだは直せる。§6.2）
- オフライン同期、印刷、Excel 出力、公開登録、農機連携、GAP、在庫、作付計画マスタの全面導入

任意（第2版の必須完了条件にはしない）とするもの:

- 作業名マスタ／改名・作物・資材・機械など周辺属性との接続（§8）
- 複数ガント行の合算％、横断ダッシュボード（§8）

## 3. 用語

第1版の用語に加え、次を用いる。

| 用語 | 意味 |
|---|---|
| 実行状態 | ガント作業（行）が持つ、日々の進捗の状態。未着手／着手中／完了の三値。 |
| 日次一覧 | 今日・今週などの期間を対象に、ガント作業を実行状態つきで並べた一覧。期間は §5.2 のとおり。 |
| 遅れ | 終了日時を過ぎても完了になっていないガント作業。 |
| メモ | 招待メンバが読む短い時系列の投稿。公開 SNS ではない。 |
| スレッド | 複数のメモを連ねた一連の記録。 |
| タグ | メモに付ける自由記述の見出し。作業名・圃場との自動一致は必須としない。 |

## 4. 利用者と運用（第2版の差分）

- 招待制・パソコン主・オンライン必須は第1版どおりとする。
- **実行状態の変更**はパソコンとする。スマホでは実行状態を変えない。
- **日次一覧**は、パソコンでは変更を含む利用、スマホでは **閲覧のみ**とする（§5.2）。
- **メモの投稿・閲覧・返信・検索・ブックマーク**は、パソコンに加えスマホでも、同じ振る舞いとする。
- 塗り・境界編集・ガントの時刻や対象の編集など、第1版でパソコン限定とした操作は、そのままパソコンとする。
- 第1版のスマホ範囲（指示の進捗色・日誌）は残し、第2版では見た目と導線をメモ・日次一覧閲覧とあわせて再構成する。

## 5. 日々の農作業タスク

### 5.1 本体

- タスクの本体は、**既存のガント作業（行）**とする。別種の「日次タスク」実体は新設しない。
- 各ガント作業に **実行状態** を持たせる。値は **未着手／着手中／完了** のみとする。
- 実行状態は、対象圃場の有無や面積％の有無にかかわらず持てる。面積％の計算規則は第1版どおり（対象付き・作業名付きの行だけ）とし、実行状態で置き換えない。

### 5.2 日次一覧

- パソコンで、**今日**および**今週**を対象にした日次一覧を出せる。一覧から実行状態を変えられる。
- 期間は **今日／今週／先週／前後7日／すべて** から選べる。今週・先週は月曜始まりとし、前後7日は今日の前後7日（今日を含む15日）とする。
- 今日・今週・前後7日のように現在を含む期間では、その期間より前に終わった **遅れ** の作業も一覧に含め、遅れと分かるようにする。遅れは、完了にするか作業を一覧から消すまで出続ける。
- 日次一覧から実行状態を変えても、作業のほかの項目（表示名・開始／終了・作業名・対象圃場）を変えない。別の画面で先に作業を直していた場合でも、その変更を戻さない。
- 作業の編集を保存するとき、読み込んだ後に別の画面で同じ作業が変わっていたら、保存せずにその旨を知らせる。
- スマホでも、同じ期間・状態フィルタ・要約（作業時間の有無・チェック進捗）で日次一覧を **閲覧**できる。スマホからは実行状態・作業時間・チェックを変えない。
- パソコンの日次一覧を使えるのは、第1版どおり圃場を1枚以上持つ利用者とする（管理者はパソコンでは持たない）。
- スマホの日次一覧閲覧は、次とする。
  - 圃場1枚以上の利用者: 自分の作業
  - 圃場0枚の利用者: 自分の作業（パソコンでは出さない）
  - 管理者: 全利用者の作業を横断（各行で利用者が分かる。パソコンでは出さない）
- 一覧には、少なくとも表示名・開始／終了・実行状態が分かる。
- 実行状態によるフィルタ（未着手／着手中／完了）ができる。

### 5.3 面積以外の実績

- 面積で測れない作業（点検、書類、資材手配、移動など）も、同じ実行状態で回せる。
- ガント作業に、任意で次を持てる。
  - **作業時間**（いつ・どれだけやったかの記録）
  - **チェック項目**（やった／まだ、の小さな確認リスト）
- **担当の割当は持たない**（第2版の対象外）。

### 5.4 予定と実績

- ガントと指示の二冊、塗りが実績の正本、という第1版の原則は変えない。
- 第2版では、予定と塗りの自動同期や必須リンクは作らない。実行状態は「自分用の予定の進み」であり、塗り面積％を上書きしない。

### 5.5 対象外（タスクまわり）

- 繰り返しルール、通知、スマホでの実行状態変更、カレンダー専用 UI の新設は対象外とする。日次一覧はガント作業の実行ビューであり、独立したカレンダー製品ではない。

## 6. X 型メモ

### 6.1 位置づけ

- メモは、短く残す現場の気づき・参考・日誌にならない記録とする。
- 塗り・％・指示・日誌を置き換えない。
- 公開 SNS・フォロー網・拡散機能は持たない。

### 6.2 投稿

- 短いテキストを時系列で投稿できる。本文の上限は **日本語 2000 文字**とする。
- **下書き**を持てる。下書きは作成者本人だけが見られる。
- 公開後は、**最後に保存した時刻から 30 分以内**であれば、本文・タグ・リンク・添付を直せる。保存のたびに期限は新たに 30 分とする。期限を過ぎたら編集できず、ソフト削除して作り直す。
- **スレッド**（入れ子の返信）ができる。
- **リンク**（URL）を複数付けられる。
- **ファイルを添付**できる。画像・動画に限らず一般的なファイルを対象とする。1 メモあたり **最大 20 ファイル**。**1 ファイルあたりのサイズ上限は設けない**（運用・基盤の都合で制限が必要になったときは、要求を改訂して明示する）。
- **タグ**は自由記述とし、1 メモに複数付けられる。作業名・圃場との自動紐づけは必須としない。
- 投稿・閲覧・返信ができるのは、**招待された利用者全員**および **管理者** とする。ソフト削除は **作成者**または **管理者** ができる。

### 6.3 閲覧・返信・検索

- 招待された利用者全員および管理者が、公開メモを読める。
- 同上の範囲が、メモに **返信**できる（入れ子可）。
- **検索**（キーワード。対象は本文・タグ・添付ファイル名）および **高度な検索**（期間・除外語・作成者）ができる。
- **ブックマーク**はメンバ共通の一覧とする。公開済みメモを付けられ、**付けた本人だけが外せる**。全員が一覧を読める。

### 6.4 タイムライン

- 主は、見えるメモの時系列一覧とする。既定は新しい公開が上。
- おすすめ・トレンド・フォロー中タイムラインは置かない。

### 6.5 ガント／タスクとの関係

- 公開済みの親メモとガント作業（行）は **任意で紐づけ**できる。必須ではない。下書き・返信には付けない。
- **1メモにつき作業は最大1件**。1作業に複数メモが付いてよい。
- 付け外しができるのは **そのメモの作成者**および **管理者**。利用者は自分の作業、管理者は全利用者の作業を選べる。
- 付け外しは本文の編集窓と独立し、パソコンとスマホの両方でできる。
- メモを読める人には、紐づいた作業の要約が見える（画面ラベルは「紐づいた作業」。別の「要約」欄は置かない）。
- 紐づけても、実行状態・塗り・面積％・作業時間・チェック・指示／日誌は自動では変わらない。
- 作業名一致やタグによる自動紐づけはしない。

### 6.6 端末

- メモの投稿・閲覧・返信・検索・ブックマーク（ファイル添付を含む）は、**パソコンとスマホの両方**で、同じ振る舞いとする。
- 別ネイティブアプリや必須のオフライン対応は第2版に含めない。同じ Web アプリの狭い画面とする。

### 6.7 対象外（メモまわり）

次は第2版のメモに含めない（詳細な対照は付録 A）。

- いいね、メンション、予約投稿、位置情報、コミュニティ
- リポスト、引用、DM、Spaces、ライブ
- 通知、編集窓が閉じたあとの公開後編集、長文 Articles、投票
- フォロー網、おすすめ、トレンド、リスト、探索、認証・収益・広告・AI

## 7. 画面の役割（第2版で足すこと）

| 場所 | 第2版で足すこと |
|---|---|
| パソコン・ガント／作業まわり | 実行状態、日次一覧（今日／今週／先週／前後7日／すべて、遅れの表示）、状態フィルタ、任意の作業時間・チェック項目 |
| パソコン・メモ | 投稿、スレッド、下書き、削除、返信、タグ、検索、ブックマーク、リンク・ファイル添付、任意のガント紐づけ（公開親・最大1作業） |
| スマホ・メモ | パソコンと同じメモの振る舞い（投稿・閲覧・返信・検索・ブックマーク・ファイル添付・任意のガント紐づけを含む） |
| スマホ・日次一覧 | 閲覧のみ（パソコンと同じ期間・遅れの表示・状態フィルタ・要約）。実行状態・時間・チェックは変えない。管理者は全利用者横断、圃場0枚は自分の作業 |
| スマホ・第1版範囲 | 指示の進捗色・日誌を残し、メモ・日次一覧と同じ導線に再構成 |

配置・見た目・経路名は詳細設計とする。

## 8. 任意（必須完了条件にしない）

次は第2版で作ってもよいが、第2版の成功条件には含めない。

- 作業名の整理（マスタや改名）、作物・資材・機械など周辺属性とタスクの接続
- 複数ガント行の合算％、全圃場・全作業の横断ダッシュボード

## 9. 第1版から引き継ぐ原則

1. 実績の正本は地図の塗りである。実行状態もメモも、塗りを捨てて置き換えない。
2. 予定の二冊（ガントと指示）を、利用者が区別できること。第2版でも自動同期しない。
3. 招待制・一人あたり規模の目安など、第1版の運用前提は維持する。
4. 作業名は一致キーである。メモのタグは自由記述であり、作業名の一致規則を変えない。

## 10. 確定した前提

1. 第2版の成功条件は、招待した利用者が、(a) パソコンで今日／今週のガント作業と遅れた作業を未着手／着手中／完了で回せ、(b) 面積以外の作業も同じ実行状態と任意の時間・チェックで扱え、(c) 招待利用者および管理者が読めるメモをパソコンとスマホで残し共有できる、ことである。あわせて、スマホで日次一覧を閲覧でき、第1版の指示・進捗色・日誌が同じスマホ導線から辿れる。
2. タスクの本体はガント作業（行）である。実行状態は三値のみである。
3. 担当・繰り返し・通知、およびスマホでの実行状態変更は第2版に含めない。スマホの日次一覧は閲覧のみとする。
4. メモは招待利用者および管理者が閲覧・返信できる。公開後は最後の保存から 30 分以内（都度延長）だけ本文・タグ・リンク・添付を直せる。本文は日本語 2000 文字まで、添付は 20 ファイルまで、ファイルサイズ上限は設けない。ブックマークは共通一覧で、付けた本人だけが外せる。メモの振る舞いはパソコンとスマホで同じとする。
5. メモとガント作業の紐づけは任意である。公開済み親メモのみ、1メモ最大1作業。作成者および管理者が付け外しでき、PC／スマホの両方でできる。自動同期はしない。
6. スマホ日次一覧の閲覧対象は、圃場あり利用者および圃場0枚は自分の作業、管理者は全利用者横断とする。パソコンの日次一覧の対象者は第2版工程1どおり（圃場1枚以上の利用者のみ）とする。

## 付録 A. X 機能と ISAS 対応（合意済み対照）

参考は既存の X（旧 Twitter）の機能面である。判定の意味は次のとおり。

| ISAS対応 | 意味 |
|---|---|
| 取り込む | 第2版メモの要求に含める |
| 捨てる | 第2版では作らない |
| 後回し | 第2版の必須にしない（将来の改訂で繰り上げ可） |

### A.1 判定の方針

1. 招待メンバおよび管理者の短い時系列メモを核とする（ポスト・入れ子スレッド・タグ・検索・ファイル添付・下書き・削除。公開後は保存から 30 分の編集窓）。
2. 拡散・おすすめ・トレンド・収益・広告・AI・音声ライブは捨てる。
3. 通知・位置情報・メンション等は後回しとする。ファイル添付は取り込む。
4. 指示・日誌・ガントと役割が重なるものは、既存を使い、メモで代替しない。

### A.2 投稿（ポスト）本体

| 機能 | 内容 | ISAS対応 |
|---|---|---|
| テキスト投稿 | 短文中心のメモ投稿 | 取り込む（上限は日本語 2000 文字） |
| スレッド | 入れ子の返信 | 取り込む |
| メディア／ファイル | 投稿への添付 | 取り込む（一般ファイル。最大 20。サイズ上限なし） |
| リンク | URL の添付 | 取り込む（複数可） |
| 投票（ポール） | 選択肢付きアンケート | 捨てる |
| 位置情報 | 投稿への場所付与 | 後回し |
| 下書き | 未公開の下書き | 取り込む（本人のみ） |
| 予約投稿 | 日時指定の公開 | 後回し |
| 投稿の編集 | 公開後の修正 | 取り込む（最後の保存から 30 分。都度延長。以降は不可） |
| 削除・非表示 | メモの削除等 | 取り込む（ソフト削除。作成者または管理者） |
| 長文記事（Articles） | ブログ寄りの長文 | 捨てる |

### A.3 反応・拡散

| 機能 | 内容 | ISAS対応 |
|---|---|---|
| いいね | 反応の表明 | 後回し |
| リポスト | 他者投稿の拡散 | 捨てる |
| 引用（Quote） | コメント付き再投稿 | 捨てる |
| 返信（リプライ） | 投稿への返信・会話 | 取り込む（利用者・管理者。入れ子可） |
| メンション | `@ユーザー` で指名 | 後回し |
| ハッシュタグ | `#話題` で紐づけ | 取り込む（自由記述。複数可） |
| ブックマーク | 後で読む保存 | 取り込む（共通一覧。外すのは付けた本人のみ） |

### A.4 タイムライン・発見

| 機能 | 内容 | ISAS対応 |
|---|---|---|
| For You（おすすめ） | アルゴリズム推薦 | 捨てる |
| Following（フォロー中） | フォロー先中心の TL | 捨てる |
| トレンド | 話題のキーワード | 捨てる |
| 検索 | キーワード・投稿検索 | 取り込む（本文・タグ・添付ファイル名） |
| 高度な検索 | 期間・除外語・作成者 | 取り込む |
| リスト | アカウント群の専用 TL | 捨てる |
| コミュニティ | テーマ別グループ投稿 | 後回し |
| 探索／話題タブ | ニュース発見 | 捨てる |

### A.5 その他（要約）

- **捨てる:** フォロー／ブロック／ミュート／鍵アカ演出、プロフィール演出、認証バッジ、DM、Spaces、ライブ、通報、アナリティクス、X Pro、Media Studio、収益、広告、ショップ、Grok、決済、Premium 階層
- **後回し:** アプリ内・プッシュ／メール通知、表示設定の拡張、二要素認証、返信相手の細分制限

### A.6 既存機能との役割分担

| 欲しいこと | 使うもの |
|---|---|
| いつ何をする予定か | ガント／作業（第1版）＋実行状態・日次一覧（第2版） |
| 他人への依頼 | 指示（第1版） |
| 依頼への「やった」 | 日誌（第1版） |
| 面積の完了 | 塗り（第1版） |
| 短く残す現場メモ・気づき | メモ（第2版） |
| メモの参考資料 | メモのファイル添付（第2版） |
