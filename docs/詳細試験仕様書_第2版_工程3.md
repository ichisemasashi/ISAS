## 2. 画面と経路

### 2.1 ブラウザの経路（詳細設計 §2.1）

| 項番 | 出典（経路） | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| V2P3-2.1-01 | `/memos` | 画面 | パソコン幅・ログイン済み（利用者または管理者） | タイムライン・投稿・検索 UI |
| V2P3-2.1-02 | `/memos/drafts` | 画面 | 同上 | 本人下書き一覧・編集・公開・削除 |
| V2P3-2.1-03 | `/memos/bookmarks` | 画面 | 同上 | 共通ブックマーク一覧。自分の印は外せる |
| V2P3-2.1-04 | ホーム出口 | 画面 | `/home`（利用者・管理者） | メモへのリンクあり（パソコン幅） |
| V2P3-2.1-05 | 狭い画面 | 画面 | 幅800px未満の `/memos*` | パソコン案内のみ。編集 UI 無し |
| V2P3-2.1-06 | 狭い画面ナビ | 画面 | 幅800px未満 | メモのナビ／ホーム入口は出ない |
| V2P3-2.1-07 | ガント紐づけ | 禁止 | `/memos` | ガント紐づけ UI が無い |
| V2P3-2.1-08 | 画面遷移 | 画面 | タイムライン→下書き→ブックマーク | 各経路がナビで辿れる |

### 2.2 `/memos`（詳細設計 §2.2）

| 項番 | 出典 | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| V2P3-2.2-01 | タイムライン | 画面 | 公開親が複数 | `published_at` 新しいものが上。返信は混ざらない |
| V2P3-2.2-02 | 投稿 | 画面 | 本文・タグ・リンク・下書き／公開 | 操作箇所寄りに結果 |
| V2P3-2.2-03 | スレッド | 画面 | 親を選択・返信公開 | 公開子孫が入れ子。返信後もスレッドは開いたまま。閉じる操作あり |
| V2P3-2.2-04 | 検索 | 画面 | キーワード／高度な検索 | 「検索結果」枠に出る。タイムラインは別。検索文字列を明示。高度な条件の開閉と検索実行は別ボタン |
| V2P3-2.2-05 | ブックマーク | 画面 | 公開メモ | 星で付け外し（自分が付けた分） |
| V2P3-2.2-06 | 空公開 | 画面 | 本文空で公開 | クライアントで止まり登録されない |
| V2P3-2.2-07 | 編集 | 画面 | 公開直後の作成者 | 編集する UI あり。編集期限を日本時間で表示 |
| V2P3-2.2-08 | 時刻表示 | 画面 | タイムライン等 | 公開時刻・編集期限は Asia/Tokyo 表示 |
| V2P3-2.2-09 | 添付 | 画面 | 投稿後／下書き／編集可 | 添付ボタンあり。投稿前は案内のみ |

### 2.3 `/memos/drafts`（詳細設計 §2.3）

| 項番 | 出典 | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| V2P3-2.3-01 | 一覧 | 画面 | 本人下書きあり | 他人の下書きは出ない |
| V2P3-2.3-02 | 公開 | 画面 | 下書きを公開 | タイムラインに親として出る（親の場合） |

### 2.4 `/memos/bookmarks`（詳細設計 §2.4）

| 項番 | 出典 | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| V2P3-2.4-01 | 並び | 画面／API | 複数ブックマーク | 最新 `created_at` 降順（同値は memo_id 降順） |
| V2P3-2.4-02 | 外し | 画面 | 自分が付けた印 | 外せる。他人の印は外せない |

### 2.5 API（詳細設計 §2.5）

| 項番 | 出典（経路・方法） | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| V2P3-2.5-01 | `GET /api/memos` | API | 公開親 | `{ok, memos}` 新しいものが上。`before_id` で続き |
| V2P3-2.5-02 | `POST /api/memos` | API | draft／published 親 | 作成。author はセッション |
| V2P3-2.5-03 | `POST /api/memos` 返信 | API | parent_id＝公開親 | 返信作成 |
| V2P3-2.5-04 | `GET /api/memos/{id}` | API | 公開／本人下書き | タグ・リンク・添付メタ付き |
| V2P3-2.5-05 | `PUT /api/memos/{id}` | API | 編集窓内・作成者 | 更新し content_saved_at 延長 |
| V2P3-2.5-06 | `DELETE /api/memos/{id}` | API | 作成者または管理者 | ソフト削除。子孫も通常一覧から消える |
| V2P3-2.5-07 | `POST .../publish` | API | 下書き | published。空本文は `body_required` |
| V2P3-2.5-08 | `GET .../replies` | API | 親 | 直下の公開・未削除返信 |
| V2P3-2.5-09 | `GET /api/memos/search` | API | q／exclude／from／to／author | 公開を対象。本人なら下書きも可（drafts=1） |
| V2P3-2.5-10 | `GET /api/memos/drafts` | API | 本人 | 本人の下書きのみ |
| V2P3-2.5-11 | 添付 POST/GET/DELETE | API | 下書きまたは編集窓 | 最大20。超過は `attachment_limit` |
| V2P3-2.5-12 | bookmark POST/DELETE | API | 公開メモ | 付与・自分の外し。`bookmark_not_found` |
| V2P3-2.5-13 | `GET /api/memos/bookmarks` | API | 共通 | §2.4 の並び |
| V2P3-2.5-14 | 未ログイン | API | Cookie 無し | `unauthorized` |
| V2P3-2.5-15 | 管理者 | API | 管理者 Cookie | 投稿・閲覧・削除可。他人本文編集は不可 |
| V2P3-2.5-16 | 検証失敗 | API | 長文・タグ過多等 | 対応する code（§2.5.3） |

## 3. 処理の規則

| 項番 | 出典 | 種別 | 手順の要点 | 期待 |
|---|---|---|---|---|
| V2P3-3.4-01 | 編集窓 | API | 公開後30分超 | `edit_window_closed` |
| V2P3-3.4-02 | 延長 | API | 窓内で保存 | content_saved_at が更新される |
| V2P3-3.4-03 | 返信追加 | API | 親の窓外 | 返信の新規は可 |
| V2P3-3.5-01 | 入れ子 | API | 返信の返信 | 深さ制限なし |
| V2P3-3.6-01 | ソフト削除連鎖 | API | 親 DELETE | 子孫も通常操作から消える |
| V2P3-3.8-01 | 二重ブックマーク | API | 同じ人が2回 | 成功のまま |
| V2P3-3.9-01 | 非連動 | 禁止 | メモ操作後 | 実行状態・塗り・指示と同期しない |
