# ADR-0011 敵対的レビュー記録票

| 項目 | 内容 |
|---|---|
| 対象 | [ADR-0011 v1](ADR-0011-オフライン地図タイル.md) |
| レビュー日 | 2026-08-15 |
| 結論 | 7件（High 3／Medium 3／Low 1）をv1へ反映。残存 **High 0／Medium 0** |

| ID | 重大度 | 攻撃／破綻 | 処置 |
|---|---|---|---|
| A11-H1 | High | 背景cache削除がoutbox削除へ波及し、圏外記録を失う | storage classと鍵を分離し、背景だけをLRU対象化 |
| A11-H2 | High | URLを知るだけで任意地域を取得できると担当範囲が漏れる | same-origin BFFでRLS・割当をrangeごとに再検証 |
| A11-H3 | High | OSM由来tileをMITだけとして配るとODbL帰属・share-alikeを欠く | manifest、画面帰属、NOTICE、SBOMを必須化 |
| A11-M1 | Medium | 国全体を端末へ配ると盗難時の漏えい・容量が過大 | bbox＋2 km、zoom 8〜16、250 MiB上限 |
| A11-M2 | Medium | 部分downloadを有効扱いすると圏外で欠損する | hash検証後の原子的manifest切替 |
| A11-M3 | Medium | assignment縮小後も旧packを閲覧できる | assignment versionで失効し削除queueへ移す |
| A11-L1 | Low | 古い地図を最新に見せる | tileset version・期限を表示し、期限切れを明示 |

権限、容量、原子更新、ライセンス、outbox非干渉を確認し、ADR-0011 v1を採用（クローズ）とする。
