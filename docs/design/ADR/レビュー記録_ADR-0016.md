# ADR-0016 敵対的レビュー記録票

| 項目 | 内容 |
|---|---|
| 対象 | [ADR-0016 v1](ADR-0016-UXデザインシステム.md) |
| レビュー日 | 2026-08-15 |
| 結論 | 6件（High 2／Medium 3／Low 1）をv1へ反映。残存 **High 0／Medium 0** |

| ID | 重大度 | 攻撃／破綻 | 処置 |
|---|---|---|---|
| A16-H1 | High | theme変更で農薬blockと通常warningが同色になり安全状態を誤認 | 最重要状態を固定semantic contract化し文言・icon併記 |
| A16-H2 | High | 見た目だけ共有してdiv clickを増やすとkeyboard操作不能 | native semanticsを原則化しkeyboard・axeをgate化 |
| A16-M1 | Medium | raw colorの増殖でdark/contrastが破綻 | 意味token以外の追加を禁止 |
| A16-M2 | Medium | component内日本語直書きで多言語化不能 | locale resourceとADR-0015 formatter境界 |
| A16-M3 | Medium | visual snapshotだけではfocus・読み上げ・200%拡大を検出できない | Testing Library、Playwright、axe、手動確認を併用 |
| A16-L1 | Low | 小規模時からStorybook運用を強制し保守対象だけ増える | 規模閾値まで既存test harnessを使う |

安全状態、アクセシビリティ、国際化、保守規模の破綻を処置し、ADR-0016 v1を採用（クローズ）とする。
