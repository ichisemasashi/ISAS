# 敵対的レビュー記録：ADR-0023 Mac本番相当ローカル統合環境

| 項目 | 内容 |
|---|---|
| 対象 | [ADR-0023 v1](ADR-0023-Mac本番相当ローカル統合環境.md) |
| 日付 | 2026-08-16 |
| 範囲 | 新ADRの方式判断、要求仕様v1.1 §5.6との整合、ADR-0004／0009／0017／0019／0020／0021への波及 |
| 結果 | **14件（High 3／Medium 9／Low 2）を全件処置。残存High 0／Medium 0** |

## 1. レビュー観点

次の攻撃仮説で、正常系の起動容易性より境界破りと成功偽装を優先して検査した。

1. local設定へproduction credential／endpointを入れると、本番を破壊または持出しできないか
2. container数、5 port、暗号化、dashboardの外形だけでHA／資源分離／KMS／SLOを証明したことにできないか
3. IdP admin、DB、telemetry、objectがLANやhostへ露出しないか
4. stop、reset、key rotation、disk不足、途中uploadで未同期／法定dataが失われないか
5. Keycloak／PostgreSQL local adapterの成功がCognito／DynamoDB／SQS／KMS／S3の成功に化けないか
6. object path、symlink、MIME、署名URL、tenant差替えからhost filesystemまたは別tenantへ越境できないか
7. telemetry、diagnostic、evidenceへtoken、secret、PII、tenant関係graphが漏れないか
8. Apple Siliconだけで動いたimageやmutable tagを、再現可能なmulti-arch構成と表示しないか
9. production mode build、build-once artifact、Production環境の三つを混同しないか
10. 既存ADRへ追記した内容が背景、決定、選択肢、帰結、受入／未解決、関連のどこかで矛盾しないか

## 5. 結論

High 3、Medium 9、Low 2はすべてADR-0023 v1または関連ADRへ反映済みで、残存High／Mediumは0である。要求仕様v1.1の責任境界、本番HA profile、release gateを弱めず、実装開始の方式入力としてクローズできる。

残るのは方式未決ではなく実装と実測である。component digest、最小host資源、arm64／amd64実行結果、fault test、runbookはADR-0023 §5の順に作成し、`verify-local-environment`が未測定をPASSにしないことを受入時に再レビューする。
