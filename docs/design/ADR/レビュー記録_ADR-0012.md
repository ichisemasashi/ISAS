# ADR-0012 敵対的レビュー記録票

| 項目 | 内容 |
|---|---|
| 対象 | [ADR-0012 v1](ADR-0012-農機連携アーキテクチャ.md) |
| レビュー日 | 2026-08-16 |
| 結論 | 8件（High 3／Medium 4／Low 1）をv1へ反映。残存 **High 0／Medium 0** |

| ID | 重大度 | 攻撃／破綻 | 処置 |
|---|---|---|---|
| A12-H1 | High | vendor adapterがDBへ直書きするとRLSと監査を迂回する | adapterを無資格の隔離processにし、commitは現在権限を再評価するimport serviceだけに限定 |
| A12-H2 | High | 散布観測の誤照合が農薬法定記録へ自動確定される | 観測を非権威に固定し、安全masterと人の確認を必須化 |
| A12-H3 | High | archive bomb、path traversal、悪性parserで取込基盤を侵害する | 展開上限、server key、malware検査、無通信sandbox、署名adapterを必須化 |
| A12-M1 | Medium | vendor ID衝突で別tenant／別machineを結合する | source namespaceを含むtenant内bindingへ変更 |
| A12-M2 | Medium | 単位／timezoneを推測して収量・散布量を誤変換する | 原値・原単位・offset・変換versionを保持し未知値は保留 |
| A12-M3 | Medium | API page途中失敗を完了扱いしデータ欠落する | 取得上限時刻、page cursor、冪等key、再開ledgerを採用 |
| A12-M4 | Medium | provider規約に反して外部API／DWHへ再配布する | connector registryで保存・再配布条件を機械gate化 |
| A12-L1 | Low | 低精度GPSで境界付近を誤った圃場へ割り当てる | confidenceと根拠を表示し、曖昧候補を管理queueへ送る |

vendor停止、法定記録への誤伝播、tenant越境、untrusted input、単位・時刻、再配布を再点検し、ADR-0012 v1を採用（クローズ）とする。
