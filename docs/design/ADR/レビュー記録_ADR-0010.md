# ADR-0010 敵対的レビュー記録票

| 項目 | 内容 |
|---|---|
| 対象 | [ADR-0010 v1](ADR-0010-地図基盤-MapLibre.md) |
| レビュー日 | 2026-08-15 |
| 結論 | 6件（High 2／Medium 3／Low 1）をv1へ反映。残存 **High 0／Medium 0** |

| ID | 重大度 | 攻撃／破綻 | 処置 |
|---|---|---|---|
| A10-H1 | High | 背景写真を境界の根拠にすると、位置ずれや古い撮影日が法定記録へ入る | PostGISだけを正本とし、画像は補助、撮影日等を表示 |
| A10-H2 | High | 任意tile URLを許すとCookie・位置・tenant情報を攻撃者へ送れる | 配備allowlistとCSP、外部送信から認証情報を除外 |
| A10-M1 | Medium | 地理院タイルをPWAが無制限cacheすると、リアルタイム利用の前提を越える | online直読だけとし、法務承認なしのcache・再配布を禁止 |
| A10-M2 | Medium | 背景停止で地図全体を利用不能にすると現場作業が止まる | overlay・一覧・記録を独立させ、背景なしを明示 |
| A10-M3 | Medium | 日本providerを海外配備へ流用すると法域・帰属条件を破る | 国別profileと審査を必須化 |
| A10-L1 | Low | libraryの浮動更新が描画を変える | 版固定と視覚・a11y・CSP回帰試験 |

圃場権威、外部送信、offline、国外展開の境界が明確であり、ADR-0010 v1を採用（クローズ）とする。
