# ADR-0013 敵対的レビュー記録票

| 項目 | 内容 |
|---|---|
| 対象 | [ADR-0013 v1](ADR-0013-外部API-Webhook.md) |
| レビュー日 | 2026-08-16 |
| 結論 | 9件（High 4／Medium 4／Low 1）をv1へ反映。残存 **High 0／Medium 0** |

| ID | 重大度 | 攻撃／破綻 | 処置 |
|---|---|---|---|
| A13-H1 | High | 任意Webhook URLでmetadata／private serviceへSSRF | 登録時・配送時DNS検証、IP deny、443固定、redirect禁止、egress allowlist |
| A13-H2 | High | 1 service tokenでtenant横断し侵害範囲が全体化 | clientを単一tenant／用途へ束縛し、現在registryとRLSで再評価 |
| A13-H3 | High | DB commit済みなのに通知消失、またはrollbackしたeventを通知 | 業務transaction内outbox＋commit済みleaseを採用 |
| A13-H4 | High | Webhookで位置・作業者・圃場を国外送信 | metadata最小payload、法域外既定拒否、項目／根拠／受領者の承認gate |
| A13-M1 | Medium | retry重複で外部が二重登録 | event／delivery ID、署名、受信側冪等契約を必須化 |
| A13-M2 | Medium | HMAC secret漏えい・rotation中断 | KMS保護、再表示禁止、key ID、期限付き二重検証 |
| A13-M3 | Medium | cursorを別tenant／filterへ流用 | cursorをtenant・filter・上限時刻・versionへ署名束縛 |
| A13-M4 | Medium | 外部API負荷が失効配送を枯渇 | P2 pool・client rate limit・body/page/concurrency上限 |
| A13-L1 | Low | response body保存で相手側secret／PIIを取り込む | status・latency・分類errorだけを保存 |

越境、SSRF、重複、順序、失効、資源枯渇を再点検し、ADR-0013 v1を採用（クローズ）とする。
