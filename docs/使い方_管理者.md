# ISAS 使い方　管理者向け

- 対象: 管理者アカウント（設定ファイルで用意された運用用アカウント）
- 入口: `/admin`（管理者ログイン）
- 関連: [利用者向け](使い方_利用者.md)、[使い方（目次）](使い方.md)、[要求仕様書.md](要求仕様書.md)、[要求仕様書_第2版.md](要求仕様書_第2版.md)

管理者は圃場・地図・ガント編集・指示・日誌を持ちません。招待の運用、利用者同士の関係の切断、進捗確定に加え、**メモの共有**と**スマホでの日次一覧の横断閲覧**ができます。

画面の見出しやボタンは「言語」で日本語／English に切り替えられます。

用語は末尾の **用語集** を参照してください。

---

## 1. はじめに

| できること | 画面 |
|---|---|
| 利用者を招待する | 招待 |
| 招待を取り消す | 取消し |
| 二人のあいだの関係を切る | 関係を切る |
| ガントの日次進捗を確定する | 進捗確定 |
| 共有メモを投稿・閲覧・検索・紐づけ | メモ |
| 全利用者の日次一覧を閲覧する | 日次（**スマホのみ**） |
| 自分のパスワードを変える／再設定する | パスワード、再設定 |

| できないこと |
|---|
| 作業場所・下地・圃場台帳・地図の塗り |
| 作業・ガントの編集、指示の作成／受け取り・日誌 |
| パソコン幅での日次一覧（「日次一覧はスマホで開いてください」） |
| 他人の対象圃場のまとめ画面 |
| 管理者アカウントを画面から増やすこと |
| 利用者入口（`/`）への管理者パスワードでのログイン |

営農の作業そのものは、別途「利用者」として招待したアカウントで行います。

### ナビ

- **パソコン**: 言語｜ホーム｜招待｜取消し｜関係を切る｜進捗確定｜メモ｜パスワード｜ログアウト
- **狭い画面**: 上部はホーム・招待・取消し・関係を切る・進捗確定・パスワード・ログアウトなど。下部ナビは **メモ｜日次｜指示**（指示は「指示は利用者ログインで開けます」と案内）

ホームには「管理者として入っています。圃場は持ちません」と出ます。パソコン幅ではメモへの出口も出ます。

---

## 2. ログイン・パスワード・ログアウト

1. `/admin` を開き、管理者のメールアドレスとパスワードで「入る」。
2. 忘れたとき: 「パスワードを忘れた」→ メールを入れて「案内を送る」→ 届いた案内から新しいパスワードを「決める」（8 文字以上）。案内は管理者入口から送ってください。
3. ログイン後に変える: 「パスワード」→ 今の／新しい／確認 →「変える」。
4. 「ログアウト」で出ます。

利用者入口と管理者入口は別です。交差して入れません。

---

## 3. 利用者を招待する

1. 「招待」を開く。
2. 相手のメールアドレスを入れて「招待する」。
3. 画面に出る「初期パスワード」を、安全な方法で相手に伝える（この画面を離れると同じ文字列は再び出せません）。
4. 相手は **利用者入口**（`/`）から、そのメールと初期パスワードで入ります。

注意:

- 招待できるのは利用者だけです。すでに利用者のメールや、管理者のメールは招待できません。
- 管理者を画面から追加する機能はありません。
- 利用者側からも招待できます。どちらの招待も、取消しは管理者の「取消し」から行います。

---

## 4. 招待の取消し

1. 「取消し」を開く。
2. 一覧から対象を選び「取り消す」。
3. 取り消したアカウントはログインできなくなります（パスワード再設定も通りません）。
4. 同じメールを、あとから再び利用者として招待することはできます（管理者メールは除く）。

取消しは「招待を無効にする」操作です。圃場データの運用ルールは利用者側の削除・関係切断とあわせて考えてください。

---

## 5. 関係を切る

一度指示の対象になった相手の圃場は、以降も互いに見えることがあります。見え方をやめるのが「関係を切る」です。切れるのは管理者だけです。

1. 「関係を切る」を開く。
2. 「メールアドレス A」「メールアドレス B」に、二人の利用者メールを入れる。
3. 「関係を切る」を実行する。

効果:

- 二人のあいだで、これまで見えていた相手の圃場が見えなくなります（双方向）。
- 指示や日誌の記録は残ります。
- あとから同じ相手へ新しい指示を出せば、その指示の対象圃場は再び見えるようになります。

切れないとき:

| 理由 | 画面の案内の例 |
|---|---|
| どちらの向きでも、まだ閉じていない指示がある | 進行中の指示がある二人は関係を切れません |
| 二人のあいだに切る対象の見え方が無い | いま見えている相手の圃場が無いので切りません |
| 利用者として切れない組み合わせ | その二人の利用者は切れません |

進行中の指示があるあいだは切れません。出した人に指示を閉じてもらってから、改めて切ってください。

---

## 6. 進捗確定

利用者のガント行について、日付ごとの進捗％を確定します（振り返り用）。管理者はガントの一覧編集はしません。

1. 「進捗確定」を開く。
2. 日付は任意（空なら東京時間の前日）。利用者メールも任意（空なら全利用者）。
3. 「確定する」。確定件数が表示されます。

すでに確定済みの日は上書きしません。無いメールアドレスはエラーになります。利用者がログインやガントを開いたときも、前日までの未確定分は自動で確定されます。

---

## 7. メモ（パソコン・スマホ）

管理者も利用者と同じメモ機能を使えます（タイムライン・下書き・ブックマーク・検索・添付・スレッド）。

1. パソコンはナビの「メモ」、スマホは下部ナビの「メモ」またはホームのタイムラインから入る。
2. 投稿・返信・検索・ブックマークの手順は [使い方_利用者.md](使い方_利用者.md) の「メモ」と同じです。
3. **削除**は作成者に加えて管理者もできます（子孫も通常一覧から消えます）。
4. **作業の紐づけ**: 公開済み親に、全利用者の未削除作業から候補を選べます（候補に利用者メールが付きます）。紐づくとスレッドに「紐づいた作業: …」と出ます。

メモは塗り・％・実行状態・指示／日誌と自動では連動しません。

---

## 8. 日次一覧（スマホのみ・横断閲覧）

管理者の日次は **狭い画面専用**です。パソコン幅では「日次一覧はスマホで開いてください」と出ます。

1. スマホ（狭い幅）で下部ナビの「日次」を開く。
2. 期間（今日／今週／先週／前後7日／すべて）と実行状態で「絞り込む」。開いた直後は前後7日です。
3. 全利用者の作業が横断で見えます（行に利用者メールが付きます）。終了日時を過ぎても完了になっていない作業には赤い「遅れ」が付き、今日・今週・前後7日では期間より前の遅れも出ます。利用者ごとの遅れの確認に使えます。完了なのに「まだ」のチェックが残る作業には、オレンジの「チェック残り」が付きます。
4. 実行状態の変更や作業の編集はできません（閲覧のみ）。
5. 圃場が 0 枚の利用者は作業を作れないため、その利用者の作業は一覧に出ません。

利用者には、システムでできないこと（スマホでの記録・指示と日次一覧の連携・繰り返しと通知）を、[使い方_利用者.md](使い方_利用者.md) の「日々の運用で気をつけること」の手順で補うよう伝えてください。

---

## 9. 言語

ナビ（およびログイン前の管理者入口）の「言語」で、日本語／English を切り替えます。

- ログイン後に選んだ言語は、管理者アカウントに残ります。
- 圃場名・作業名・依頼文・メモ本文などは入力内容のままです（翻訳しません）。管理者画面では主にボタンや見出しが切り替わります。

---

## 10. 運用の目安

1. 知っている相手だけを招待する（公開登録は無い）。
2. 初期パスワードは画面に一度だけ出るので、その場で確実に伝える。
3. 退職・誤招待などは「取消し」でログインを止める。
4. 利用者同士の見え方をやめたいときは、進行中の指示が無いことを確認してから「関係を切る」。
5. 必要なら「進捗確定」で前日分などをまとめて確定する。
6. 共有の連絡や気づきは「メモ」を使う。作業と紐づけるときは公開親メモから。
7. 横断の予定確認はスマホの「日次」で行う。
8. 管理者自身が圃場を持つ必要があるときは、別メールで利用者として招待する（管理者アカウントでは営農画面を使いません）。

---

## 11. 利用者への案内（短い伝え方）

相手が利用者として使い始めるとき、次を伝えると迷いにくいです。

1. 入口は `/`（利用者ログイン）。管理者入口ではない。
2. 初回は渡した初期パスワードで入り、すぐにパスワードを変える。
3. 地図・塗り・作業・ガント・指示の作成はパソコンで。スマホはメモ・日次の閲覧・指示の進捗と日誌向き。
4. 詳しい手順は [使い方_利用者.md](使い方_利用者.md)。

---

## 用語集

操作でよく出る語です。[使い方.md](使い方.md) の共通用語集と同じ内容です。

| 用語 | 意味 |
|---|---|
| 利用者 | 招待された営農用アカウント。入口は `/`。圃場や地図・指示などを使う |
| 管理者 | 運用用アカウント。入口は `/admin`。招待の取消し・関係の切断などが主な仕事。圃場は持たない |
| 招待 | メールアドレスを登録し、初期パスワードを一度だけ画面に出すこと。公開登録はない |
| 取消し | 管理者が利用者の招待を無効にし、ログインできなくすること |
| 初期パスワード | 招待直後に一度だけ表示される仮パスワード。画面を離れると同じ文字列は再表示できない |
| 圃場 | 利用者ごとの区画。台帳と地図の形で管理する |
| 作業場所 | 地図の対象範囲。下地取込の基準になる |
| 下地 | 作業場所に重ねる背景画像（空中写真・標準地図・衛星など） |
| 作業名 | 塗り・進捗％・指示などで一致キーになる名前。完全一致（「田植え」と「田植」は別） |
| 作業タイトル（表示名） | 作業一覧やガントの棒に出る名前。題名や作業名とは別 |
| 題名 | ガント上で作業をまとめるグループ名 |
| 作業 | 開始・終了などを持つ予定行。作業画面／ガントで管理する |
| 実行状態 | 作業の進捗段階。未着手／着手中／完了 |
| 日次一覧 | 今日・今週・先週・前後7日・すべてで作業を実行状態つきで見る一覧 |
| 遅れ | 終了日時を過ぎても完了になっていない作業。日次一覧で赤い「遅れ」が付く |
| チェック残り | 完了なのに「まだ」のチェック項目が残っている作業。日次一覧でオレンジの「チェック残り」が付く |
| 作業時間 | 作業に付けた実際の時間帯の明細 |
| チェック項目 | 作業に付けたやることリスト（まだ／やった） |
| ソフト削除 | 一覧から消すが履歴は残す削除。作業の「一覧から消す」、メモの「削除」など |
| 塗り | 地図上で作業名ごとに塗った実績。進捗色（未／一部／済）の正本 |
| パーセント（％） | 対象圃場の面積に対する、その作業名の塗り面積の割合 |
| 指示 | 他人への依頼票。日付・時刻・作業名・受け手・対象圃場を持つ |
| 受け手／出した人 | 指示を受け取った人／出した人 |
| 日誌 | 受け手が指示に対して書く「やった」記録。1人1通。訂正不可 |
| 関係の切断 | 管理者が二人のあいだの見え方をやめる操作。指示・日誌の記録は残る |
| メモ | 招待メンバと管理者が共有する短い時系列の記録（タイムライン） |
| 親メモ／返信 | スレッドの起点となる投稿／その下の返信 |
| 下書き | 本人だけが見られる未公開メモ |
| 編集窓 | 公開後、最後の保存から30分以内だけ本文などを直せる期間（保存のたびに延長） |
| 紐づいた作業 | 公開親メモに任意で付けたガント作業の要約表示。別欄の「要約」はない |
| 進捗確定 | 管理者が日付ごとのガント進捗％を確定する操作。利用者のログイン時にも前日分は自動確定される |
| 狭い画面（スマホ幅） | おおよそスマホ相当の幅。編集系の入口を隠し、下部ナビ（メモ／日次／指示）を出す |
